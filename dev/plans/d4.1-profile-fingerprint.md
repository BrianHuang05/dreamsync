## Goal

Implement `profile_fingerprint()` — a function that computes a short, deterministic hex string from a `ProfileConfig`'s compilation-relevant content. This fingerprint becomes the second half of the cache's composite key `(track_id, profile_fingerprint)`.

Two profiles with identical palettes, moods, effects, and transitions produce the same fingerprint regardless of cosmetic fields (`description`, `author`, `tags`, `source_path`).

---

## ProfileConfig Reference

From `src/dreamsync/profile.py`:

```python
@dataclass(frozen=True)
class ProfileConfig:
    name: str
    palettes: dict[str, tuple[str, ...]]          # palette_name -> hex colors
    moods: dict[str, MoodProfileConfig]            # "chill"|"groove"|"hype"|"drop" -> MoodProfileConfig
    description: str = ""
    author: str = ""
    tags: tuple[str, ...] = ()
    version: int = 1
    source_path: Path | None = None
    transitions: tuple[TransitionRule, ...] = ()
    cycle_interval: float | None = None

@dataclass(frozen=True)
class MoodProfileConfig:
    palettes: tuple[str, ...]                      # palette names referenced
    effects: tuple[MoodEffectEntry, ...] = ()
    params: dict[str, Any] = field(default_factory=dict)

@dataclass(frozen=True)
class MoodEffectEntry:
    name: str
    weight: float

@dataclass(frozen=True)
class TransitionRule:
    from_mood: str
    to_mood: str
    palette: str
```

### Compilation-relevant fields (INCLUDED in fingerprint)

| Field | Why |
|-------|-----|
| `name` | Identifies the profile conceptually; changing it means a different profile |
| `palettes` | Directly determines colors in `ShowCue.color_palette` |
| `moods` | Each mood's `palettes`, `effects` (name + weight), and `params` flow through `TreatmentSelector` |
| `transitions` | `TransitionRule`s (`from_mood`, `to_mood`, `palette`) flow through `TransitionPlanner` |

### Cosmetic fields (EXCLUDED from fingerprint)

| Field | Why excluded |
|-------|-------------|
| `description` | Display-only, never reaches compiler |
| `author` | Display-only |
| `tags` | Display-only |
| `source_path` | Set by `load_profile()` based on disk location — not content |
| `version` | Always 1, never varies |
| `cycle_interval` | Not used by `compile_show()` — it's a runtime playback hint |

## Algorithm — Step by Step

### Step 1: Handle None

```python
if profile is None:
    return "00000000"
```

`None` means "built-in defaults" — always the same, so a fixed sentinel.

### Step 2: Build canonical dict

Build a pure-Python dict containing only compilation-relevant fields, with all collections sorted to eliminate ordering variation:

```python
canonical = {
    "name": profile.name,
    "palettes": _canonical_palettes(profile.palettes),
    "moods": _canonical_moods(profile.moods),
    "transitions": _canonical_transitions(profile.transitions),
}
```

#### `_canonical_palettes(palettes: dict[str, tuple[str, ...]]) -> list`

```python
# Sort by palette name for determinism.
# Values (color tuples) are already ordered — don't re-sort (order matters for rendering).
return sorted(
    [[name, list(colors)] for name, colors in palettes.items()]
)
```

Example output:
```python
[["aurora", ["#00FF00", "#FF00FF"]], ["sunset", ["#FF5500", "#FF8800"]]]
```

#### `_canonical_moods(moods: dict[str, MoodProfileConfig]) -> list`

```python
result = []
for mood_name in sorted(moods):
    mood = moods[mood_name]
    result.append([
        mood_name,
        sorted(mood.palettes),                                # palette refs, sorted
        sorted([[e.name, e.weight] for e in mood.effects]),   # effects, sorted by name
        sorted(mood.params.items()),                          # params, sorted by key
    ])
return result
```

Example output:
```python
[
    ["chill", ["aurora"], [["breathe", 1.0]], [["breathe_rate_mult", 0.6]]],
    ["drop",  ["sunset"], [["pulse", 1.0]],  [["pulse_decay", 0.3]]],
    ...
]
```

#### `_canonical_transitions(transitions: tuple[TransitionRule, ...]) -> list`

```python
return sorted(
    [[r.from_mood, r.to_mood, r.palette] for r in transitions]
)
```

Example output:
```python
[["chill", "groove", "sunset"], ["groove", "hype", "aurora"]]
```

### Step 3: Serialize to canonical JSON

```python
json_str = json.dumps(canonical, sort_keys=True, separators=(",", ":"))
```

- `sort_keys=True` — ensures the top-level keys (`moods`, `name`, `palettes`, `transitions`) are alphabetically ordered.
- `separators=(",", ":")` — no whitespace, compact form.
- The inner lists are already sorted by Step 2, so `sort_keys` only affects the outer dict.

### Step 4: SHA-256 → 8 hex chars

```python
return hashlib.sha256(json_str.encode("utf-8")).hexdigest()[:8]
```

## Implementation — `src/dreamsync/cache.py`

Create the new file with these contents (D4.1 scope only):

```python
"""Show Cache — file-based cache for compiled ShowTimelines.

Provides:
- profile_fingerprint(): deterministic hex fingerprint from ProfileConfig content
- ShowCache: file-based KV store keyed by (track_id, profile_fingerprint)
- cached_compile_show(): cache-aware wrapper around compile_show()
"""

from __future__ import annotations

import hashlib
import json
import logging

from dreamsync.profile import ProfileConfig

logger = logging.getLogger(__name__)

# ---------------------------------------------------------------------------
# D4.1 — Profile Fingerprint
# ---------------------------------------------------------------------------

_NONE_FINGERPRINT = "00000000"


def profile_fingerprint(profile: ProfileConfig | None) -> str:
    """Compute an 8-char hex fingerprint of a profile's compilation-relevant content.

    Only fields that affect compile_show() output are included:
    name, palettes, moods (palettes/effects/params), and transitions.

    Returns "00000000" for None (built-in defaults).
    """
    if profile is None:
        return _NONE_FINGERPRINT

    canonical = {
        "name": profile.name,
        "palettes": _canonical_palettes(profile.palettes),
        "moods": _canonical_moods(profile.moods),
        "transitions": _canonical_transitions(profile.transitions),
    }
    json_str = json.dumps(canonical, sort_keys=True, separators=(",", ":"))
    return hashlib.sha256(json_str.encode("utf-8")).hexdigest()[:8]


def _canonical_palettes(palettes: dict[str, tuple[str, ...]]) -> list:
    """Sort palettes by name; preserve color order within each palette."""
    return sorted(
        [[name, list(colors)] for name, colors in palettes.items()]
    )


def _canonical_moods(moods: dict) -> list:
    """Sort moods by name; sort each mood's palettes, effects, and params."""
    result = []
    for mood_name in sorted(moods):
        mood = moods[mood_name]
        result.append([
            mood_name,
            sorted(mood.palettes),
            sorted([[e.name, e.weight] for e in mood.effects]),
            sorted(mood.params.items()),
        ])
    return result


def _canonical_transitions(transitions: tuple) -> list:
    """Sort transitions by (from_mood, to_mood, palette) for determinism."""
    return sorted(
        [[r.from_mood, r.to_mood, r.palette] for r in transitions]
    )
```

**Note**: Only the fingerprint-related code is added in this step. D4.2–D4.4 will add to this file incrementally.

```python
"""Tests for profile_fingerprint() — D4.1."""

import pytest

from dreamsync.cache import profile_fingerprint
from dreamsync.profile import (
    MoodEffectEntry,
    MoodProfileConfig,
    ProfileConfig,
    TransitionRule,
)


def _make_profile(**kwargs) -> ProfileConfig:
    """Build a minimal valid ProfileConfig with overridable fields."""
    defaults = dict(
        name="test_profile",
        palettes={
            "warm": ("#FF0000", "#FF8800", "#FFFF00"),
            "cool": ("#0000FF", "#0088FF", "#00FFFF"),
        },
        moods={
            "chill": MoodProfileConfig(
                palettes=("cool",),
                effects=(MoodEffectEntry("breathe", 1.0),),
                params={"breathe_rate_mult": 0.6},
            ),
            "groove": MoodProfileConfig(
                palettes=("warm",),
                effects=(MoodEffectEntry("scroll", 0.7), MoodEffectEntry("wave", 0.3)),
                params={},
            ),
            "hype": MoodProfileConfig(
                palettes=("warm",),
                effects=(MoodEffectEntry("pulse", 1.0),),
                params={"pulse_decay": 0.3},
            ),
            "drop": MoodProfileConfig(
                palettes=("warm", "cool"),
                effects=(MoodEffectEntry("pulse", 0.8), MoodEffectEntry("wave", 0.2)),
                params={"pulse_decay": 0.15},
            ),
        },
        transitions=(
            TransitionRule("chill", "groove", "warm"),
            TransitionRule("groove", "hype", "warm"),
        ),
    )
    defaults.update(kwargs)
    return ProfileConfig(**defaults)
```

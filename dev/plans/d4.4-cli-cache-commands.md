## Goal

Add three new CLI subcommands (`cache-list`, `cache-clear`, `cache-info`) for cache inspection and management, plus a `--cache-dir` flag on the existing `compile` and `compile-and-play` subcommands to enable cache-aware compilation from the CLI.

---

## New Subcommands

### `dreamsync cache-list [--cache-dir DIR]`

Displays a table of all cached shows with summary statistics.

**Output — entries exist:**

```
Show Cache: 12 entries (3.2 MB) in ~/.dreamsync/cache

Track                        Artist           Profile          Compiled At           Size
────────────────────────────────────────────────────────────────────────────────────────────
Blinding Lights              The Weeknd       midnight_rave    2026-03-04 14:23:01   4.8 KB
Bohemian Rhapsody            Queen            midnight_rave    2026-03-03 22:10:45   8.1 KB
Bohemian Rhapsody            Queen            chill_ambient    2026-03-03 22:15:12   7.9 KB
```

**Output — empty cache:**

```
Show Cache: 0 entries (0 B) in ~/.dreamsync/cache

Cache is empty.
```

### `dreamsync cache-clear [--track-id ID] [--cache-dir DIR] [--yes/-y]`

- **No `--track-id`**: Clears entire cache. Prompts for confirmation unless `--yes`.
- **With `--track-id`**: Clears all entries for that specific track (all profile variants).
- Prints count of deleted entries.

**Output examples:**

```
# Full clear with prompt
Clear all 12 cached shows? [y/N]: y
Deleted 12 cached shows.

# Per-track clear
Deleted 2 cached shows for track 4iV5W6fMJg0KuzBpVbG3E0.

# Nothing to delete
No cached shows found for track xyz123.
```

### `dreamsync cache-info [--cache-dir DIR]`

Compact summary of cache statistics.

```
Show Cache Info
  Directory:   ~/.dreamsync/cache
  Entries:     12
  Tracks:      8
  Disk usage:  3.2 MB
```

## Modified Subcommands

### `compile --cache-dir DIR`

When `--cache-dir` is provided, the compile command uses the cache:

1. Derive `track_id = path_based_track_id(args.structure_path)`.
2. Create `ShowCache(args.cache_dir)`.
3. Use `cached_compile_show()` instead of `compile_show()`.
4. Print cache hit/miss status.

**Behavior**:
- Cache hit → load from cache, skip compilation, print `"Cache hit — loaded from cache"`.
- Cache miss → compile normally, store result, print `"Cache miss — compiled and cached"`.
- Without `--cache-dir` → existing behavior unchanged (no cache involvement).

### `compile-and-play --cache-dir DIR`

Same as `compile`, but integrated into the analyze+compile+play pipeline:

1. Derive `track_id = path_based_track_id(args.mp3_path)`.
2. Create `ShowCache(args.cache_dir)`.
3. Check cache first. If hit → skip BOTH analysis and compilation.
4. If miss → analyze → compile → store → play.
5. Print cache status.

### Handler logic in `main()`

#### `cache-list` handler

```python
if args.command == "cache-list":
    from .cache import ShowCache

    cache = ShowCache(args.cache_dir)
    s = cache.stats()
    entries = cache.list_entries()

    size_str = _format_bytes(s.total_bytes)
    print(f"Show Cache: {s.entry_count} entries ({size_str}) in {s.cache_dir}\n")

    if not entries:
        print("Cache is empty.")
        return 0

    # Table header
    print(f"{'Track':<28} {'Artist':<16} {'Profile':<16} {'Compiled At':<21} {'Size':>8}")
    print("─" * 93)

    for e in entries:
        # Truncate long fields
        track = e.track_name[:27]
        artist = e.artist[:15]
        prof = e.profile_name[:15]
        # Format compiled_at — trim to seconds
        compiled = e.compiled_at[:19].replace("T", " ") if e.compiled_at != "unknown" else "unknown"
        size = _format_bytes(e.file_size)
        print(f"{track:<28} {artist:<16} {prof:<16} {compiled:<21} {size:>8}")

    return 0
```

#### `cache-clear` handler

```python
if args.command == "cache-clear":
    from .cache import ShowCache

    cache = ShowCache(args.cache_dir)

    if args.track_id:
        count = cache.invalidate(args.track_id)
        if count:
            print(f"Deleted {count} cached show{'s' if count != 1 else ''} for track {args.track_id}.")
        else:
            print(f"No cached shows found for track {args.track_id}.")
    else:
        s = cache.stats()
        if s.entry_count == 0:
            print("Cache is already empty.")
            return 0

        if not args.yes:
            answer = input(f"Clear all {s.entry_count} cached shows? [y/N]: ")
            if answer.lower() != "y":
                print("Aborted.")
                return 0

        count = cache.clear()
        print(f"Deleted {count} cached show{'s' if count != 1 else ''}.")

    return 0
```

#### Helper: `_format_bytes()`

Add as a module-level helper in `cli.py`:

```python
def _format_bytes(n: int) -> str:
    """Format byte count for human display."""
    if n < 1024:
        return f"{n} B"
    elif n < 1024 * 1024:
        return f"{n / 1024:.1f} KB"
    elif n < 1024 * 1024 * 1024:
        return f"{n / (1024 * 1024):.1f} MB"
    else:
        return f"{n / (1024 * 1024 * 1024):.1f} GB"
```

if args.command == "compile":
    from .analyzer.models import SongStructure
    from .compiler import compile_show
    from .compiler.compile import format_summary
    ...
    structure = SongStructure.from_json(args.structure_path)
    profile = _resolve_profile_from_args(args)
    if profile == "error":
        return 1

    # --- Cache-aware compilation ---
    if args.cache_dir:
        from .cache import ShowCache, cached_compile_show, path_based_track_id
        cache = ShowCache(args.cache_dir)
        track_id = path_based_track_id(args.structure_path)
        timeline, from_cache = cached_compile_show(

    # --- Rest of existing output logic unchanged ---

        ...

#### Modified `compile-and-play` handler

Same pattern, but also skips analysis on cache hit:

```python
if args.command == "compile-and-play":
    ...
    mp3_path = args.mp3_path
    ...

    # --- Cache-aware path ---
    if args.cache_dir:
        from .cache import ShowCache, cached_compile_show, path_based_track_id
        cache = ShowCache(args.cache_dir)
        track_id = path_based_track_id(mp3_path)

        # Check cache BEFORE analyzing
        if cache.has(track_id, profile):
            timeline = cache.get(track_id, profile)
            print("Cache hit — skipping analysis and compilation")
        else:
            # Cache miss — run full pipeline
            print("Cache miss — analyzing and compiling...")
            structure = analyze_song(mp3_path)
            timeline, _ = cached_compile_show(
                structure, profile, cache=cache, track_id=track_id, seed=args.seed,
            )
    else:
        # Original path — no cache
        structure = analyze_song(mp3_path)
        timeline = compile_show(structure, profile, seed=args.seed)

    # --- Playback logic unchanged ---
    ...
```

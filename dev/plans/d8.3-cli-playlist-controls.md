## Goal

Extend the CLI to support playlist sources (directories, M3U files) and interactive controls during multi-track playback. The `play` subcommand auto-detects whether the positional argument is a single file, directory, or M3U file and creates the appropriate `PlaylistManager`. New `--shuffle` and `--repeat` flags control playlist behavior. During playback, a keyboard listener thread provides next/prev/quit controls.

```python
@classmethod
def from_path(cls, path, **kwargs):
    path = Path(path)
    if path.is_dir():
        return cls.from_directory(path, **kwargs)
    elif path.suffix.lower() in (".m3u", ".m3u8"):
        return cls.from_m3u(path, **kwargs)
    elif path.is_file():
        return cls.from_file(path, **kwargs)
    else:
        raise FileNotFoundError(f"Path not found: {path}")
```

### 4. Keyboard listener

A daemon thread that reads single characters from stdin and dispatches control signals.

```python
def _start_keyboard_listener(session_ref, stop_event, *, debug=False):
    """Start a daemon thread that listens for keyboard input.

    Controls:
    - 'n' or right arrow → next track
    - 'p' or left arrow → previous track
    - 'q' → quit session
    """
    import sys
    import msvcrt  # Windows; use termios on Unix

    def _listener():
        if debug:
            print("[controls] n=next, p=prev, q=quit")

        while not stop_event.is_set():
            try:
                if sys.platform == "win32":
                    import msvcrt
                    if msvcrt.kbhit():
                        ch = msvcrt.getch().decode("utf-8", errors="ignore").lower()
                        _handle_key(ch, session_ref, stop_event)
                else:
                    # Unix: use select on stdin
                    import select
                    if select.select([sys.stdin], [], [], 0.1)[0]:
                        ch = sys.stdin.read(1).lower()
                        _handle_key(ch, session_ref, stop_event)
            except Exception:
                pass
            time.sleep(0.05)

    thread = threading.Thread(target=_listener, daemon=True, name="keyboard-input")
    thread.start()
    return thread


def _handle_key(ch, session_ref, stop_event):
    """Handle a single keypress."""
    session = session_ref[0]
    if ch == "n" and session is not None:
        session.signal_next()
    elif ch == "p" and session is not None:
        session.signal_prev()
    elif ch == "q":
        stop_event.set()
```

## Usage Examples

```bash
# Play a directory (alphabetical order)
dreamsync play ./music/ --config devices.yaml

# Play a directory (shuffled)
dreamsync play ./music/ --config devices.yaml --shuffle

# Play a directory (looping)
dreamsync play ./music/ --config devices.yaml --repeat

# Play an M3U playlist
dreamsync play party.m3u --config devices.yaml

# Play an M3U shuffled and looping
dreamsync play party.m3u --config devices.yaml --shuffle --repeat

# Single file (same as Feature 7)
dreamsync play song.mp3 --config devices.yaml

# During playback:
# Press 'n' → skip to next track
# Press 'p' → go to previous track
# Press 'q' or Ctrl+C → stop session
```

## Platform Considerations

### Windows (primary target)

- Use `msvcrt.kbhit()` and `msvcrt.getch()` for non-blocking keyboard input.
- Available without any additional dependencies.

### Unix/macOS (secondary)

- Use `select.select([sys.stdin], [], [], timeout)` for non-blocking stdin read.
- May need `tty.setraw()` + `termios` for single-character input without Enter.
- Fallback: if terminal raw mode setup fails, skip keyboard controls and log a message.

### Both platforms

- Keyboard listener runs on a daemon thread — automatically cleaned up on process exit.
- Ctrl+C is handled by the signal handler (sets `stop_event`), not the keyboard listener.

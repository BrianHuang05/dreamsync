## Description

This sub-component replaces the current `StreamCapturePipeline` instantiation in `session.py` with the new `CaptureOrchestrator`. The old pipeline was a synchronous, feed-based approach where `capture_pipeline.feed()` was called on every audio frame from the PortAudio loop. The new orchestrator runs its own FFmpeg capture subprocess independently, so it only needs to be constructed, configured, and started — it does not need frame-level data from the feature extraction audio loop.

The replacement occurs in the `run_session()` function, specifically in the "4e. Capture pipeline" section (currently lines 168-207). The new code constructs an `OrchestratorConfig` from the existing `capture_dir` and `capture_naming` session parameters, then creates a `CaptureOrchestrator` with an `on_segment_saved` callback that prints the saved filename and metadata.

The `check_ffmpeg()` guard is preserved — if FFmpeg is not found on PATH, capture is skipped with a warning. This ensures backward compatibility for users who have not installed FFmpeg.

### New Code to Insert

Replace with:

```python
# 4e. Capture pipeline (CaptureOrchestrator — independent FFmpeg capture)
capture_orchestrator = None
if capture:
    from dreamsync.capture.writer import check_ffmpeg

    if not check_ffmpeg():
        print("Capture: ffmpeg not found on PATH. Install ffmpeg to enable song capture.")
        print("Continuing without capture.")
    else:
        from dreamsync.capture.orchestrator import CaptureOrchestrator, OrchestratorConfig

        orch_cfg = OrchestratorConfig(
            sample_rate=48000,       # PCM capture at 48kHz (independent of feature extraction rate)
            channels=2,              # Stereo capture
            output_dir=capture_dir,
            naming=capture_naming,
            log_dir=str(Path(capture_dir) / "logs"),
        )
        capture_orchestrator = CaptureOrchestrator(
            config=orch_cfg,
            on_segment_saved=lambda path, meta: print(
                f"Capture: saved {Path(path).name} "
                f"({meta.get('artist', 'unknown')} - {meta.get('song_title', 'unknown')})"
            ),
        )
        print(f"Capture: enabled -> {capture_dir}/ (naming={capture_naming})")
```

### Key Changes from Old to New

| Aspect | Old (`StreamCapturePipeline`) | New (`CaptureOrchestrator`) |
|--------|-------------------------------|------------------------------|
| Audio source | PortAudio via `feed()` per frame | FFmpeg subprocess (independent) |
| Sample rate | Uses session `sample_rate` (44100) | Fixed 48kHz for high-quality capture |
| Channels | Uses session `channels` (1 mono) | Fixed 2 stereo for MP3 capture |
| Config class | `CaptureConfig` + `BufferConfig` + `WriterConfig` | Single `OrchestratorConfig` |
| Spotify integration | Inline after construction | Moved to D5.3 (separate step) |
| Variable name | `capture_pipeline` | `capture_orchestrator` |
| Callback signature | `on_song_saved(path: Path, meta: dict)` | `on_segment_saved(path: str, meta: dict)` |
| Log directory | Not configurable | `{capture_dir}/logs` |

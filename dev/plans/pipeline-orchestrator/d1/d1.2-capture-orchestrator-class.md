## Description

`CaptureOrchestrator` is the top-level class that owns and coordinates every sub-module in the audio capture pipeline. Its constructor instantiates all modules using values from a single `OrchestratorConfig`, but critically **does not start anything** — no threads are spawned, no subprocesses are launched, no I/O occurs. This separation between construction and activation is essential for testability and predictable lifecycle management.

The constructor also accepts an optional `on_segment_saved` callback that will be invoked whenever a segment is finalized (encoder closes + sidecar written). This callback is stored during `__init__` and wired into the data path in D2.

### Class Definition

```python
class CaptureOrchestrator:
    """Top-level orchestrator for the audio capture pipeline.

    Aggregates all sub-modules and manages the full capture lifecycle.
    Construction is side-effect-free — no threads or processes are spawned
    until :meth:`start` is called.

    Parameters
    ----------
    config:
        Unified pipeline configuration.  Defaults to ``OrchestratorConfig()``.
    on_segment_saved:
        Optional callback invoked after each segment is finalized.
        Signature: ``(mp3_path: str, metadata: dict) -> None``.
    """

    def __init__(
        self,
        config: OrchestratorConfig | None = None,
        on_segment_saved: Callable[[str, dict], None] | None = None,
    ) -> None:
        self._config = config or OrchestratorConfig()
        self._on_segment_saved = on_segment_saved

        # --- Module instantiation (no side effects) ---

        # Logging — must be first so other modules can log during init
        self._logger = PipelineLogger(
            log_dir=self._config.log_dir,
        )

        # Capture subprocess manager
        self._capture = CaptureProcessManager(
            config=self._config.to_capture_config(),
        )

        # Thread-safe PCM buffer (producer/consumer bridge)
        self._buffer = AudioBuffer(
            max_chunks=self._config.buffer_max_chunks,
            sample_rate=self._config.sample_rate,
        )

        # Boundary queue for segment split points
        self._boundary_queue = BoundaryQueue(
            safety_margin_frames=self._config.safety_margin_frames,
        )

        # Output file naming
        self._file_namer = FileNamer(
            output_dir=self._config.output_dir,
            pattern=self._config.naming,
        )

        # JSON sidecar writer
        self._metadata_writer = MetadataWriter(
            output_dir=self._config.output_dir,
        )

        # Drift detection and correction
        self._drift = DriftDetector(
            sample_rate=self._config.sample_rate,
            boundary_queue=self._boundary_queue,
            warning_threshold=self._config.drift_warning_threshold,
            correction_threshold=self._config.drift_correction_threshold,
            critical_threshold=self._config.drift_critical_threshold,
        )

        # External timing source integration
        self._timing = TimingIntegrator(
            boundary_queue=self._boundary_queue,
            get_current_frame=lambda: self._buffer.frames_processed,
            sample_rate=self._config.sample_rate,
            refresh_interval=self._config.timing_refresh_interval,
        )

        # Failure recovery
        self._recovery = RecoveryManager(
            capture_manager=self._capture,
            config=self._config.to_recovery_config(),
        )

        # --- Runtime state (set by start/stop) ---
        self._running = False
        self._producer_thread: threading.Thread | None = None
        self._consumer_thread: threading.Thread | None = None
        self._start_time: float | None = None
        self._segments_completed: int = 0
```

### Module-to-Config Mapping

Each sub-module receives **only** the config values it needs, derived from `OrchestratorConfig`:

| Module | Attribute | Config fields used |
|--------|-----------|-------------------|
| `PipelineLogger` | `self._logger` | `log_dir` |
| `CaptureProcessManager` | `self._capture` | `sample_rate`, `channels`, `device_pattern` (via `to_capture_config()`) |
| `AudioBuffer` | `self._buffer` | `buffer_max_chunks`, `sample_rate` |
| `BoundaryQueue` | `self._boundary_queue` | `safety_margin_frames` |
| `FileNamer` | `self._file_namer` | `output_dir`, `naming` |
| `MetadataWriter` | `self._metadata_writer` | `output_dir` |
| `DriftDetector` | `self._drift` | `sample_rate`, `drift_warning_threshold`, `drift_correction_threshold`, `drift_critical_threshold`, plus `self._boundary_queue` |
| `TimingIntegrator` | `self._timing` | `sample_rate`, `timing_refresh_interval`, plus `self._boundary_queue` and `self._buffer.frames_processed` (via lambda) |
| `RecoveryManager` | `self._recovery` | `capture_restart_delay`, `max_capture_retries`, `encoder_retry_count` (via `to_recovery_config()`), plus `self._capture` |

### Key Design Decisions

1. **Lambda for `get_current_frame`**: `TimingIntegrator` needs a callable that returns the current frame count. We use `lambda: self._buffer.frames_processed` so it always reads the live value from `AudioBuffer` without the timing integrator needing a direct reference to the buffer.

2. **`PipelineLogger` initialized first**: Logging infrastructure is set up before any other module, so that if a module logs during its own `__init__`, the logger is ready.

3. **No `SplitProcessor` in `__init__`**: The `SplitProcessor` requires boundary data that is only available after `start()` is called, so it is created lazily in the `start()` method (D1.3). A `None` placeholder is not stored — it simply does not exist until needed.

4. **FileNamer creates output directory**: `FileNamer.__init__` calls `mkdir(parents=True, exist_ok=True)` on `output_dir`, which is a filesystem side-effect. This is acceptable because it is idempotent and required for any subsequent operation.

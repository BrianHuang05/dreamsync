## Description

The orchestrator exposes two read-only properties that let callers inspect pipeline state without reaching into internal sub-modules:

1. **`is_running`** — A boolean indicating whether the pipeline is actively capturing audio. This is the primary guard used by CLI code and external integrations to decide whether operations like `stop()` or `update_timing()` are meaningful.

2. **`stats`** — A dictionary snapshot of all pipeline counters aggregated from sub-modules. This provides a single-call summary for monitoring, logging, and CLI status displays. Values are read at call time (not cached), so they always reflect the current state.

Both properties are thread-safe because they read from atomic Python attributes or thread-safe sub-module properties.

## Implementation Details

### File
`src/dreamsync/capture/orchestrator.py` (add properties to `CaptureOrchestrator` class)

### is_running Property

```python
@property
def is_running(self) -> bool:
    """Whether the capture pipeline is actively running.

    Returns ``True`` after :meth:`start` and before :meth:`stop`
    completes.  Thread-safe (reads a single boolean).
    """
    return self._running
```

The `_running` attribute is set to `True` in `start()` (just before threads launch) and set to `False` in `stop()` (before thread joins begin). Because Python's GIL ensures atomic reads/writes of booleans, no explicit lock is needed.

### stats Property

```python
@property
def stats(self) -> dict:
    """Return a snapshot of pipeline statistics.

    All values are read at call time and reflect the current state
    of each sub-module.  Safe to call from any thread.

    Returns
    -------
    dict with the following keys:

    - ``segments_completed`` (int): Number of segments fully encoded
      and saved to disk.
    - ``frames_processed`` (int): Total PCM frames accepted by the
      buffer.
    - ``elapsed_seconds`` (float): Wall-clock seconds since
      ``start()`` was called, or 0.0 if not running.
    - ``drift_corrections`` (int): Number of boundary corrections
      applied by the drift detector.
    - ``capture_restarts`` (int): Number of times the FFmpeg capture
      process was restarted after a failure.
    - ``encoder_failures`` (int): Number of encoder process failures
      encountered.
    - ``gaps`` (int): Number of gap records logged by recovery
      (i.e., periods of missing audio data).
    """
    elapsed = 0.0
    if self._start_time is not None:
        elapsed = time.monotonic() - self._start_time

    return {
        "segments_completed": self._segments_completed,
        "frames_processed": self._buffer.frames_processed,
        "elapsed_seconds": round(elapsed, 3),
        "drift_corrections": self._drift.corrections_applied,
        "capture_restarts": self._recovery.total_capture_restarts,
        "encoder_failures": self._recovery.total_encoder_failures,
        "gaps": len(self._recovery.gaps),
    }
```

### Field Descriptions

| Key | Type | Source | Initial Value |
|-----|------|--------|---------------|
| `segments_completed` | `int` | `self._segments_completed` (orchestrator-internal counter, incremented in D2 when a segment finishes) | 0 |
| `frames_processed` | `int` | `self._buffer.frames_processed` — total frames put into `AudioBuffer` | 0 |
| `elapsed_seconds` | `float` | `time.monotonic() - self._start_time`, rounded to 3 decimal places. Returns `0.0` if `_start_time is None` (not started or already stopped). | 0.0 |
| `drift_corrections` | `int` | `self._drift.corrections_applied` — number of times `DriftDetector.correct()` adjusted boundaries | 0 |
| `capture_restarts` | `int` | `self._recovery.total_capture_restarts` — FFmpeg restart count | 0 |
| `encoder_failures` | `int` | `self._recovery.total_encoder_failures` — encoder process failure count | 0 |
| `gaps` | `int` | `len(self._recovery.gaps)` — count of `GapRecord` entries (periods of missing audio) | 0 |

### Thread Safety Notes

- `_running` is a Python `bool`, which has atomic read/write semantics under the GIL.
- `_segments_completed` is an `int` read from the main thread; incremented only on the consumer thread (no race).
- `AudioBuffer.frames_processed` is guarded by an internal `threading.Lock` (see `pcm_buffer.py`).
- `DriftDetector.corrections_applied` is a simple `int` read (atomic under GIL).
- `RecoveryManager.total_capture_restarts` and `.total_encoder_failures` are simple `int` reads.
- `RecoveryManager.gaps` returns a copy of the internal list (see `recovery_manager.py`).
- `time.monotonic()` is thread-safe.

### Elapsed Time Behavior

| Pipeline state | `_start_time` | `elapsed_seconds` |
|----------------|---------------|--------------------|
| Before `start()` | `None` | `0.0` |
| After `start()` | Set to `time.monotonic()` | Increases in real-time |
| After `stop()` | Reset to `None` | `0.0` |

This means `elapsed_seconds` represents a live timer during capture and resets to zero when stopped. The final elapsed time is logged in the `pipeline.stopped` event (D1.3) before `_start_time` is cleared.

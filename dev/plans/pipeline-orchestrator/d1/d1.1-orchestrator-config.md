## Description

`OrchestratorConfig` is a single, frozen dataclass that aggregates every tunable parameter across all pipeline sub-modules into one object. Instead of passing 10+ separate config objects around, the orchestrator accepts one `OrchestratorConfig` and derives the per-module configs internally.

The dataclass is frozen (immutable) so that configuration cannot be mutated after the pipeline starts. Every field has a default value that matches the corresponding sub-module default, so `OrchestratorConfig()` with no arguments produces valid, production-ready configuration.

This dataclass also provides convenience methods to derive the typed config objects expected by each sub-module, ensuring the orchestrator never passes raw kwargs.

### Dataclass Definition
```python
@dataclass(frozen=True)
class OrchestratorConfig:
    """Unified configuration for the entire capture pipeline.

    Every field has a default that matches the corresponding sub-module
    default so that ``OrchestratorConfig()`` is immediately usable.
    """

    # --- Capture process (-> CaptureConfig) ---
    sample_rate: int = 48000
    channels: int = 2
    device_pattern: str = "CABLE Output"

    # --- PCM reader ---
    chunk_ms: int = 100

    # --- AudioBuffer ---
    buffer_max_chunks: int = 10

    # --- Encoding (-> EncoderProcess) ---
    bitrate: str = "192k"

    # --- Output paths (-> FileNamer, MetadataWriter) ---
    output_dir: str = "./captured_songs"
    naming: str = "timestamp"      # "timestamp" | "metadata"
    log_dir: str = "./logs"

    # --- Timing (-> BoundaryQueue, TimingIntegrator) ---
    safety_margin_frames: int = 24_000   # 0.5 s at 48 kHz
    timing_refresh_interval: float = 5.0

    # --- Drift (-> DriftDetector) ---
    drift_warning_threshold: float = 0.1
    drift_correction_threshold: float = 0.5
    drift_critical_threshold: float = 2.0

    # --- Recovery (-> RecoveryManager) ---
    capture_restart_delay: float = 0.2
    max_capture_retries: int = 5
    encoder_retry_count: int = 1
```

### Derived Config Methods

These methods create the typed config objects consumed by each sub-module. They live on `OrchestratorConfig` itself so that derivation logic is co-located with the config definition.

```python
    def to_capture_config(self) -> CaptureConfig:
        """Derive a CaptureConfig for CaptureProcessManager."""
        return CaptureConfig(
            sample_rate=self.sample_rate,
            channels=self.channels,
            device_pattern=self.device_pattern,
        )

    def to_recovery_config(self) -> RecoveryConfig:
        """Derive a RecoveryConfig for RecoveryManager."""
        return RecoveryConfig(
            capture_restart_delay=self.capture_restart_delay,
            max_capture_retries=self.max_capture_retries,
            encoder_retry_count=self.encoder_retry_count,
        )
```

### Default-Value Alignment Table

The following defaults **must** match their sub-module counterparts exactly:

| OrchestratorConfig field | Sub-module | Sub-module default |
|--------------------------|------------|--------------------|
| `sample_rate` = 48000 | `CaptureConfig.sample_rate` | 48000 |
| `channels` = 2 | `CaptureConfig.channels` | 2 |
| `device_pattern` = "CABLE Output" | `CaptureConfig.device_pattern` | "CABLE Output" |
| `buffer_max_chunks` = 10 | `AudioBuffer(max_chunks=10)` | 10 |
| `bitrate` = "192k" | `EncoderProcess(bitrate="192k")` | "192k" |
| `output_dir` = "./captured_songs" | `FileNamer(output_dir="./output")` | **Override** (orchestrator default is `./captured_songs`) |
| `naming` = "timestamp" | `FileNamer(pattern="timestamp")` | "timestamp" |
| `log_dir` = "./logs" | `PipelineLogger(log_dir="./logs")` | "./logs" |
| `safety_margin_frames` = 24000 | `BoundaryQueue(safety_margin_frames=24000)` | 24000 |
| `timing_refresh_interval` = 5.0 | `TimingIntegrator(refresh_interval=5.0)` | 5.0 |
| `drift_warning_threshold` = 0.1 | `DriftDetector(warning_threshold=0.1)` | 0.1 |
| `drift_correction_threshold` = 0.5 | `DriftDetector(correction_threshold=0.5)` | 0.5 |
| `drift_critical_threshold` = 2.0 | `DriftDetector(critical_threshold=2.0)` | 2.0 |
| `capture_restart_delay` = 0.2 | `RecoveryConfig.capture_restart_delay` | 0.2 |
| `max_capture_retries` = 5 | `RecoveryConfig.max_capture_retries` | 5 |
| `encoder_retry_count` = 1 | `RecoveryConfig.encoder_retry_count` | 1 |

Note: `output_dir` intentionally differs from `FileNamer`'s own default (`./output`) because the orchestrator provides its own convention (`./captured_songs`). The orchestrator default overrides the sub-module default.

### Usage Example

```python
# Default config — all sub-module defaults
cfg = OrchestratorConfig()

# Custom config for low-latency capture
cfg = OrchestratorConfig(
    chunk_ms=50,
    buffer_max_chunks=20,
    safety_margin_frames=12_000,  # 0.25 s
    drift_warning_threshold=0.05,
)

# Derive sub-module configs
capture_cfg = cfg.to_capture_config()
recovery_cfg = cfg.to_recovery_config()
```

## Description

The orchestrator has three lifecycle methods that manage the full capture pipeline:

- **`start()`** — Begins audio capture and spawns the producer/consumer threads that form the data pipeline.
- **`stop()`** — Performs an orderly shutdown: stops capture, drains the buffer, finalizes the last segment, and joins all threads.
- **`shutdown()`** — A safe wrapper around `stop()` that catches exceptions, logs errors, and guarantees cleanup. Idempotent.

These methods transition the orchestrator through a clear state machine: `IDLE -> RUNNING -> STOPPING -> IDLE`. The `_running` flag is the primary state indicator, guarded to prevent double-start or stop-before-start issues.

### start() Method

```python
def start(self, device_name: str | None = None) -> None:
    """Start the capture pipeline.

    Parameters
    ----------
    device_name:
        Full DirectShow device name for FFmpeg.  If ``None``, the
        ``CaptureProcessManager`` will auto-discover using the
        configured ``device_pattern``.

    Raises
    ------
    RuntimeError
        If the pipeline is already running.
    """
    if self._running:
        raise RuntimeError("Pipeline is already running")

    # 1. Log startup
    self._logger.log(
        "pipeline.started",
        category="lifecycle",
        data={"device": device_name or self._config.device_pattern},
    )

    # 2. Start FFmpeg capture subprocess
    self._capture.start(device_name)

    # 3. Record start time for drift measurement
    self._start_time = time.monotonic()

    # 4. Create and start producer thread
    self._producer_thread = threading.Thread(
        target=self._producer_loop,
        name="capture-producer",
        daemon=True,
    )

    # 5. Create and start consumer thread
    self._consumer_thread = threading.Thread(
        target=self._consumer_loop,
        name="capture-consumer",
        daemon=True,
    )

    # 6. Mark running BEFORE starting threads
    self._running = True

    self._producer_thread.start()
    self._consumer_thread.start()
```

### Producer Loop (private method)

```python
def _producer_loop(self) -> None:
    """Read PCM chunks from FFmpeg stdout and feed them into the buffer.

    Runs on the producer thread.  Exits when the capture stream
    reaches EOF (i.e. FFmpeg is stopped) or on exception.
    """
    try:
        for chunk in read_chunks(self._capture.stdout, self._config.chunk_ms):
            if not self._running:
                break
            self._buffer.put(chunk)
    except Exception as exc:
        self._logger.log(
            "producer.error",
            level="ERROR",
            category="lifecycle",
            data={"error": str(exc)},
        )
    finally:
        # Signal downstream that no more data is coming
        self._buffer.signal_eof()
```

### Consumer Loop (private method)

```python
def _consumer_loop(self) -> None:
    """Read chunks from the buffer and route them to the split processor.

    Runs on the consumer thread.  Exits when the buffer yields None
    (EOF sentinel from the producer).

    Note: SplitProcessor integration is wired in D2.  In D1, this
    method establishes the loop structure with a placeholder for
    chunk processing.
    """
    try:
        while True:
            chunk = self._buffer.get()
            if chunk is None:
                # EOF sentinel — producer is done
                break
            # D2 will add: self._split_processor.process_chunk(chunk)
    except Exception as exc:
        self._logger.log(
            "consumer.error",
            level="ERROR",
            category="lifecycle",
            data={"error": str(exc)},
        )
    finally:
        # D2 will add: finalize last segment, write sidecar
        pass
```

### stop() Method

```python
def stop(self) -> None:
    """Stop the capture pipeline gracefully.

    Performs an orderly shutdown:
    1. Stops FFmpeg (causes producer to hit EOF)
    2. Waits for producer to drain and signal EOF to buffer
    3. Waits for consumer to process remaining chunks
    4. Stops periodic timing refresh
    5. Joins both threads

    No-op if the pipeline is not running.
    """
    if not self._running:
        return

    # 1. Log stopping
    self._logger.log(
        "pipeline.stopping",
        category="lifecycle",
    )

    # 2. Mark not running to unblock any waiting loops
    self._running = False

    # 3. Stop FFmpeg — closes stdout, causing read_chunks() EOF
    try:
        self._capture.stop()
    except Exception as exc:
        self._logger.log(
            "capture.stop_error",
            level="WARNING",
            category="lifecycle",
            data={"error": str(exc)},
        )

    # 4. Stop TimingIntegrator periodic refresh
    try:
        self._timing.stop_periodic()
    except Exception:
        pass  # best-effort

    # 5. Join threads with timeout
    join_timeout = 10.0  # seconds

    if self._producer_thread is not None:
        self._producer_thread.join(timeout=join_timeout)
        if self._producer_thread.is_alive():
            self._logger.log(
                "producer.join_timeout",
                level="WARNING",
                category="lifecycle",
            )

    if self._consumer_thread is not None:
        self._consumer_thread.join(timeout=join_timeout)
        if self._consumer_thread.is_alive():
            self._logger.log(
                "consumer.join_timeout",
                level="WARNING",
                category="lifecycle",
            )

    # 6. Log stopped with summary
    self._logger.log(
        "pipeline.stopped",
        category="lifecycle",
        data=self.stats,
    )

    # 7. Reset thread references
    self._producer_thread = None
    self._consumer_thread = None
    self._start_time = None
```

### shutdown() Method

```python
def shutdown(self) -> None:
    """Safe shutdown wrapper — idempotent, exception-safe.

    Calls :meth:`stop` in a try/except, logs any exceptions, and
    always cleans up.  Safe to call multiple times.
    """
    try:
        self.stop()
    except Exception as exc:
        self._logger.log(
            "shutdown.error",
            level="ERROR",
            category="lifecycle",
            data={"error": str(exc)},
        )
    finally:
        self._running = False
```

### Thread Architecture

```
Main thread           Producer thread          Consumer thread
    │                      │                        │
    ├─ start()             │                        │
    │   ├─ capture.start() │                        │
    │   ├─ Thread.start()──┤                        │
    │   └─ Thread.start()──│────────────────────────┤
    │                      │                        │
    │                      ├─ read_chunks()         │
    │                      │   └─ buffer.put()──────┤
    │                      │                   get()│
    │                      │              process() │
    │                      │                        │
    ├─ stop()              │                        │
    │   ├─ capture.stop()  │                        │
    │   │                  ├─ EOF → signal_eof()    │
    │   │                  │                   None │
    │   │                  │              finalize()│
    │   ├─ join()──────────┤                        │
    │   └─ join()──────────│────────────────────────┤
    │                      │                        │
```

### Edge Cases

- **`stop()` before `start()`**: Returns immediately because `self._running is False`.
- **`shutdown()` after `shutdown()`**: First call runs `stop()`, second call sees `_running is False` and returns. No error.
- **`start()` after `stop()`**: Currently raises `RuntimeError` if capture subprocess cannot be restarted. Future work may support re-initialization.
- **Producer exception**: Logs the error and still calls `signal_eof()` so the consumer does not hang.
- **Consumer exception**: Logs the error. The `finally` block ensures cleanup runs.
- **Thread join timeout**: Logs a warning but does not raise. The daemon flag on threads ensures they will not block interpreter shutdown.

Call `orch.stop()` to clean up.

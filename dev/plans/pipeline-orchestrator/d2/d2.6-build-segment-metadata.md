## Description

The `_build_segment_metadata()` method constructs a `SegmentMetadata` dataclass for a completed segment. This dataclass captures everything needed to reconstruct the context of a segment after the fact: frame positions, audio parameters, song information from the external timing source (Spotify), the output file path, and any gaps in the audio stream caused by capture failures.

The method is called from `_on_segment_complete()` (D2.4) just before writing the JSON sidecar file. It merges data from three sources:

1. **Frame positions** — `start_frame` and `end_frame` from `SplitProcessor`'s frame counter.
2. **Audio config** — `sample_rate`, `channels`, `bitrate` from the orchestrator config.
3. **External metadata** — `song_title`, `artist`, `album` from `BoundaryQueue` entries (ultimately from `TimingIntegrator` / Spotify).
4. **Encoder state** — `output_file` path from the `EncoderProcess`.
5. **Recovery state** — `gaps` list from `RecoveryManager`, recording any periods of lost audio.

This method also relies on `FileNamer` for naming patterns. The `FileNamer` generates filenames in two patterns:

- **Timestamp pattern** (default): `YYYY-MM-DD_HH-MM-SS_segment_NNNNNN.mp3`
- **Metadata pattern**: `YYYY-MM-DD_HH-MM-SS_Artist_-_Title.mp3`

The pattern is selected based on `FileNamer`'s `pattern` config and whether metadata with `artist`/`song_title` is available.

### Implementation

```python
def _build_segment_metadata(
    self, segment_index: int, start_frame: int, end_frame: int
) -> SegmentMetadata:
    # 1. Get song metadata from BoundaryQueue
    boundary_meta = self._get_segment_metadata(segment_index)

    # 2. Get gap records from RecoveryManager
    #    RecoveryManager.gaps returns list[GapRecord]
    #    Convert to list[dict] for SegmentMetadata.gaps field
    gaps = [
        {
            "start_frame": g.start_frame,
            "end_frame": g.end_frame,
            "duration_frames": g.duration_frames,
            "timestamp": g.timestamp,
        }
        for g in self._recovery.gaps
    ]

    # 3. Build the SegmentMetadata dataclass
    return SegmentMetadata(
        start_frame=start_frame,
        end_frame=end_frame,
        sample_rate=self._config.sample_rate,
        channels=self._config.channels,
        bitrate=self._config.bitrate,
        segment_index=segment_index,
        song_title=boundary_meta.get("song_title") if boundary_meta else None,
        artist=boundary_meta.get("artist") if boundary_meta else None,
        album=boundary_meta.get("album") if boundary_meta else None,
        output_file=self._encoders[segment_index].output_path,
        gaps=gaps,
    )
```

### SegmentMetadata Dataclass Reference

```python
@dataclass
class SegmentMetadata:
    """All metadata for a single output segment."""

    start_frame: int = 0
    end_frame: int = 0
    sample_rate: int = 48000
    channels: int = 2
    bitrate: str = "192k"
    segment_index: int = 0
    song_title: str | None = None
    artist: str | None = None
    album: str | None = None
    planned_start_time: str | None = None
    planned_end_time: str | None = None
    source_timing_data: dict | None = None
    output_file: str | None = None
    capture_session_id: str | None = None
    gaps: list[dict] = field(default_factory=list)

    @property
    def segment_duration_frames(self) -> int:
        return self.end_frame - self.start_frame

    @property
    def segment_duration_seconds(self) -> float:
        return self.segment_duration_frames / self.sample_rate
```

### _get_segment_metadata() Helper Reference (from D2.3)

```python
def _get_segment_metadata(self, segment_index: int) -> dict | None:
    """Retrieve metadata from BoundaryQueue for the given segment.

    Returns a dict with keys like 'song_title', 'artist', 'album',
    or None if no metadata is available.
    """
    entry = self._boundary_queue.peek_next()
    if entry is not None and entry.metadata is not None:
        return entry.metadata
    return None
```

The `BoundaryEntry.metadata` dict is populated by `TimingIntegrator` (D3) from Spotify track data. Example:

### RecoveryManager.gaps Reference

```python
class RecoveryManager:
    @property
    def gaps(self) -> list[GapRecord]:
        """Return a copy of all gap records."""
        return list(self._gaps)

@dataclass
class GapRecord:
    """Records a gap in the audio stream caused by a capture failure."""
    start_frame: int
    end_frame: int = 0
    duration_frames: int = 0
    timestamp: float = 0.0
```

Gaps are recorded when `RecoveryManager.handle_capture_failure()` successfully restarts the capture process. The gap `start_frame` is the last known good frame position before the failure. The `end_frame` is set to the same value initially (unknown actual gap duration).

### FileNamer Filename Patterns

The `FileNamer` class generates output filenames used by the encoder factory (D2.3). Two patterns are supported:

**Timestamp pattern** (default, `pattern="timestamp"`):
```
{output_dir}/YYYY-MM-DD_HH-MM-SS_segment_NNNNNN.mp3
```
Example: `./output/2025-06-15_14-30-22_segment_000001.mp3`

**Metadata pattern** (`pattern="metadata"`):
```
{output_dir}/YYYY-MM-DD_HH-MM-SS_Artist_-_Title.mp3
```
Example: `./output/2025-06-15_14-30-22_Queen_-_Bohemian_Rhapsody.mp3`

The metadata pattern requires both `artist` and `song_title` in the metadata dict. If either is missing, the timestamp pattern is used as fallback. Filenames are sanitized via `sanitize()` which replaces illegal filesystem characters with underscores.

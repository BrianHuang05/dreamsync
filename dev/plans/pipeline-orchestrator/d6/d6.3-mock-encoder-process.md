# D6.3 — Mock Encoder Process

## Deliverable
D6 — Integration Tests

## Prerequisites
- `EncoderProcess` interface from `src/dreamsync/capture/encoder_process.py` -- the mock must match its public API: `start()`, `write(data)`, `close()`, `wait(timeout)`, `is_alive()`, `.output_path` property, `.stderr_output` property
- Understanding of how `SplitProcessor` interacts with encoders: calls `start()` once, `write(data)` many times, `close()` once, then the orchestrator calls `wait()` to check the exit code

## Description

`MockEncoderProcess` is a test double that replaces `EncoderProcess` in integration tests. Instead of spawning a real FFmpeg subprocess to encode PCM data into MP3, it simply writes the raw PCM bytes directly to the output file. This allows integration tests to verify that the correct bytes were routed to each segment's encoder without requiring FFmpeg to be installed.

The output files produced by `MockEncoderProcess` will contain raw PCM data rather than valid MP3, but this is intentional -- the tests verify byte counts, frame accuracy, and segment boundaries rather than audio codec correctness. The raw PCM output is actually easier to verify: you can directly compare byte counts against expected frame counts using the formula `expected_bytes = frames * BYTES_PER_FRAME`.

The mock also supports the `wait()` method (returns 0 for success) and `stderr_output` property (returns empty list) so that the orchestrator's encoder lifecycle management works identically to production.

### Class Definition

```python
class MockEncoderProcess:
    """Drop-in replacement for EncoderProcess that writes raw bytes to disk.

    Instead of encoding PCM to MP3 via FFmpeg, this mock writes the raw
    PCM bytes directly to the output file.  This allows byte-exact
    verification of split accuracy in integration tests.

    Parameters
    ----------
    output_path:
        Full path for the output file.  The file is created on ``start()``
        and closed on ``close()``.
    **kwargs:
        Accepted for API compatibility with ``EncoderProcess`` constructor
        (which accepts ``sample_rate``, ``channels``, ``bitrate``, etc.)
        but all keyword arguments are ignored.
    """

    def __init__(self, output_path: str, **kwargs) -> None:
        self._output_path = output_path
        self._file = None
        self._bytes_written: int = 0
        self._kwargs = kwargs  # stored but unused, for debugging

    @property
    def output_path(self) -> str:
        """Path to the output file."""
        return self._output_path

    @property
    def bytes_written(self) -> int:
        """Total bytes written to the output file."""
        return self._bytes_written

    def start(self) -> None:
        """Open the output file for writing.

        Creates parent directories if they do not exist.
        """
        import os
        os.makedirs(os.path.dirname(self._output_path) or ".", exist_ok=True)
        self._file = open(self._output_path, "wb")

    def write(self, data: bytes) -> None:
        """Write raw PCM data to the output file.

        In production, ``EncoderProcess.write()`` feeds data into FFmpeg's
        stdin pipe.  Here we write directly to the output file.

        Raises
        ------
        RuntimeError
            If the file has not been opened via ``start()`` or has already
            been closed.
        """
        if self._file is None or self._file.closed:
            raise RuntimeError("Encoder not started or already closed")
        self._file.write(data)
        self._bytes_written += len(data)

    def close(self) -> None:
        """Close the output file.

        Safe to call multiple times -- subsequent calls are no-ops.
        """
        if self._file is not None and not self._file.closed:
            self._file.close()

    def wait(self, timeout: float = 30.0) -> int:
        """Wait for the encoder to finish and return exit code.

        Always returns 0 (success) since there is no subprocess to wait for.
        The ``timeout`` parameter is accepted for API compatibility but ignored.
        """
        return 0

    def is_alive(self) -> bool:
        """Return True if the output file is currently open for writing."""
        return self._file is not None and not self._file.closed

    @property
    def stderr_output(self) -> list[str]:
        """Return FFmpeg stderr lines.  Always empty for the mock."""
        return []
```

### API Compatibility Table

| EncoderProcess method | MockEncoderProcess behavior |
|-----------------------|----------------------------|
| `__init__(output_path, **kwargs)` | Stores path, ignores kwargs |
| `start()` | Opens file in `"wb"` mode |
| `write(data)` | Writes raw bytes to file, increments counter |
| `close()` | Closes file (idempotent) |
| `wait(timeout=30.0)` | Returns `0` immediately |
| `is_alive()` | Returns `True` if file is open |
| `.output_path` (property) | Returns the output file path |
| `.stderr_output` (property) | Returns `[]` |

### Factory Function for SplitProcessor

`SplitProcessor` expects a `start_encoder(segment_index) -> encoder` callable. In integration tests, create a factory that returns `MockEncoderProcess` instances:

```python
def make_mock_encoder_factory(output_dir: str, extension: str = ".mp3"):
    """Return a factory function compatible with SplitProcessor.start_encoder."""
    def factory(segment_index: int):
        path = os.path.join(output_dir, f"segment_{segment_index:06d}{extension}")
        encoder = MockEncoderProcess(path)
        encoder.start()
        return encoder
    return factory
```

This factory is not part of `MockEncoderProcess` itself but is a test utility pattern documented here for use in D6.4+ tests.

### Byte Verification Pattern

After a test run, verify output file sizes:

```python
import os
from dreamsync.capture.pcm_reader import BYTES_PER_FRAME

# For a song of duration_seconds at 48kHz stereo:
expected_frames = int(duration_seconds * 48000)
expected_bytes = expected_frames * BYTES_PER_FRAME  # * 4

actual_bytes = os.path.getsize(output_path)
assert actual_bytes == expected_bytes, (
    f"Expected {expected_bytes} bytes ({expected_frames} frames), "
    f"got {actual_bytes} bytes ({actual_bytes // BYTES_PER_FRAME} frames)"
)
```

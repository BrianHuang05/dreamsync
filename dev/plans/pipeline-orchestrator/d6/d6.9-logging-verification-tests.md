## Description

These tests verify that the pipeline produces correct structured log output in JSONL format. Structured logging is essential for post-session diagnostics, automated monitoring, and debugging capture issues. The `PipelineLogger` writes to both the console (human-readable) and a file (`logs/pipeline.jsonl` in JSONL format).

The tests focus on the JSONL file output because it is machine-parseable and deterministic. Three properties are verified:
1. **File existence and format**: The `pipeline.jsonl` file is created and every line is valid JSON.
2. **Key event coverage**: The essential lifecycle events (`started`, `segment_complete`, `stopped`) all appear in the log.
3. **Summary statistics**: The `stopped` event includes summary data such as `segments_completed` count and `elapsed_seconds`.

These tests exercise the `PipelineLogger` in the context of a full pipeline run (or a simulated one), ensuring that all the right log calls are made at the right times.

### Pipeline Run with Logging

The test wires `PipelineLogger` to emit events at each pipeline stage:

```python
class TestLoggingIntegration:
    """Verify structured JSONL logging during pipeline operation."""

    def _run_pipeline_with_logging(
        self,
        pcm_data: bytes,
        boundaries: list[int],
        output_dir: str,
        log_dir: str,
    ) -> Path:
        """Run a pipeline with logging enabled, return the log file path.

        Returns
        -------
        Path
            Path to the ``pipeline.jsonl`` log file.
        """
        logger = PipelineLogger(
            log_dir=log_dir,
            console_level="WARNING",  # Suppress console output in tests
            file_level="DEBUG",
        )
        log_file = Path(log_dir) / "pipeline.jsonl"

        # Emit start event
        logger.capture_event("started", frame_position=0)

        output_files = []
        segments_completed = 0
        start_time = time.monotonic()

        def start_encoder(segment_index: int):
            path = os.path.join(output_dir, f"segment_{segment_index:06d}.mp3")
            output_files.append(path)
            encoder = MockEncoderProcess(path)
            encoder.start()
            return encoder

        def on_segment_complete(segment_index, start_frame, end_frame):
            nonlocal segments_completed
            segments_completed += 1
            logger.split_event(
                "segment_complete",
                frame_position=end_frame,
                segment_index=segment_index,
                start_frame=start_frame,
                end_frame=end_frame,
            )

        processor = SplitProcessor(
            boundaries=boundaries,
            start_encoder=start_encoder,
            on_segment_complete=on_segment_complete,
        )

        mock_capture = MockCaptureProcess(pcm_data)
        mock_capture.start()
        processor.run(read_chunks(mock_capture.stdout, chunk_ms=100))
        mock_capture.stop()

        elapsed = time.monotonic() - start_time

        # Emit stop event with summary
        logger.capture_event(
            "stopped",
            frame_position=processor.current_frame,
            segments_completed=segments_completed,
            elapsed_seconds=round(elapsed, 3),
            total_bytes_written=processor.total_bytes_written,
        )

        return log_file
```

### JSONL Parsing Helpers

```python
def _read_log_events(log_file: Path) -> list[dict]:
    """Read all events from a JSONL log file."""
    events = []
    with open(log_file, "r", encoding="utf-8") as f:
        for line in f:
            line = line.strip()
            if line:
                events.append(json.loads(line))
    return events

def _find_events_by_name(events: list[dict], event_name: str) -> list[dict]:
    """Filter events by the 'event' field value."""
    return [e for e in events if e.get("event") == event_name]
```

### JSONL Line Format Reference

Each line in `pipeline.jsonl` looks like:

```json
{"timestamp": "2026-03-04T12:34:56.789012+00:00", "level": "INFO", "category": "capture", "event": "started", "data": null, "frame_position": 0}
```

Key fields:
- `timestamp`: ISO 8601 UTC timestamp
- `level`: Python logging level name (DEBUG, INFO, WARNING, ERROR)
- `category`: Pipeline subsystem (capture, encoder, split, boundary, timing, recovery)
- `event`: Event name (started, segment_complete, stopped, etc.)
- `data`: Optional dict with event-specific data (null if no extra data)
- `frame_position`: Pipeline frame counter at the time of the event

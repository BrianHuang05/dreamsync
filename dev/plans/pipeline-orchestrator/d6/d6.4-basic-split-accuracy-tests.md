## Description

These tests verify the core promise of the capture pipeline: that a continuous multi-song PCM stream is split into separate per-song output files at exact frame boundaries. This is the most fundamental integration test class -- if splits are inaccurate, every downstream feature (metadata, naming, etc.) is built on a broken foundation.

The tests use `MockCaptureProcess` to feed synthetic multi-song PCM through the pipeline and `MockEncoderProcess` to capture the raw bytes written to each segment file. By using raw byte output (not actual MP3 encoding), the tests can assert exact byte counts and verify frame-perfect split accuracy.

Each test follows a common pattern:
1. Generate multi-song PCM with known durations
2. Compute expected boundary frame positions from the durations
3. Wire `MockCaptureProcess` -> `AudioBuffer` -> `SplitProcessor` -> `MockEncoderProcess` instances
4. Run the pipeline
5. Assert: correct number of output files, correct byte count per file, correct total byte count

```python
class TestBasicSplitAccuracy:
    """Verify that multi-song PCM is split into correct per-song files."""

    def _run_pipeline(
        self,
        pcm_data: bytes,
        boundaries: list[int],
        output_dir: str,
    ) -> list[str]:
        """Wire and run the split pipeline, returning output file paths.

        Parameters
        ----------
        pcm_data:
            Raw PCM bytes (from generate_multi_song_pcm or generate_sine_pcm).
        boundaries:
            Cumulative frame positions where splits should occur.
            E.g., for songs of [5s, 3s, 7s] at 48kHz: [240000, 384000].
            The list has len(songs) - 1 entries.
        output_dir:
            Directory where MockEncoderProcess writes output files.

        Returns
        -------
        list[str]
            Paths to all output files produced, in segment order.
        """
        output_files = []

        def start_encoder(segment_index: int):
            path = os.path.join(output_dir, f"segment_{segment_index:06d}.raw")
            output_files.append(path)
            encoder = MockEncoderProcess(path)
            encoder.start()
            return encoder

        segments_completed = []

        def on_segment_complete(segment_index, start_frame, end_frame):
            segments_completed.append({
                "segment_index": segment_index,
                "start_frame": start_frame,
                "end_frame": end_frame,
            })

        processor = SplitProcessor(
            boundaries=boundaries,
            start_encoder=start_encoder,
            on_segment_complete=on_segment_complete,
        )

        # Feed PCM through the processor using read_chunks
        mock_capture = MockCaptureProcess(pcm_data)
        mock_capture.start()
        processor.run(read_chunks(mock_capture.stdout, chunk_ms=100))
        mock_capture.stop()

        return output_files
```

### Boundary Calculation Helper

```python
def _compute_boundaries(durations: list[float], sample_rate: int = 48000) -> list[int]:
    """Convert song durations to cumulative frame boundaries.

    For N songs, returns N-1 boundaries.  Each boundary is the cumulative
    frame count at the end of a song (which is also the start of the next).

    Example: [5.0, 3.0, 7.0] -> [240000, 384000]
    """
    boundaries = []
    cumulative = 0
    for dur in durations[:-1]:  # No boundary after the last song
        cumulative += int(dur * sample_rate)
        boundaries.append(cumulative)
    return boundaries
```

### Byte Count Assertion Helper

```python
def _assert_file_size(
    path: str,
    expected_frames: int,
    tolerance_frames: int = 0,
) -> None:
    """Assert that a file has the expected size in frames (±tolerance)."""
    actual_bytes = os.path.getsize(path)
    actual_frames = actual_bytes // BYTES_PER_FRAME
    expected_bytes = expected_frames * BYTES_PER_FRAME
    if tolerance_frames == 0:
        assert actual_bytes == expected_bytes, (
            f"Expected {expected_frames} frames ({expected_bytes} bytes), "
            f"got {actual_frames} frames ({actual_bytes} bytes)"
        )
    else:
        assert abs(actual_frames - expected_frames) <= tolerance_frames, (
            f"Expected {expected_frames}±{tolerance_frames} frames, "
            f"got {actual_frames} frames"
        )
```

## Test Cases

- [ ] `test_three_songs_produce_three_files` — Generate multi-song PCM with `durations = [5.0, 5.0, 5.0]` (15 seconds total, 3 songs of equal length). Compute boundaries as `[240000, 480000]`. Run the pipeline via `_run_pipeline()`. Assert: exactly 3 output files are produced (`segment_000000.raw`, `segment_000001.raw`, `segment_000002.raw`). Assert: each file is approximately `240000 * 4 = 960000` bytes (5 seconds at 48kHz stereo). Assert: sum of all file sizes equals the total PCM input size.

- [ ] `test_split_frame_accuracy` — Generate multi-song PCM with `durations = [3.0, 4.0]` (2 songs). Boundary at frame `144000` (3.0s * 48000). Run the pipeline. Assert: file 0 has exactly `144000 * 4 = 576000` bytes. Assert: file 1 has exactly `192000 * 4 = 768000` bytes. Assert: total bytes written (`576000 + 768000 = 1344000`) equals `len(pcm_data)`. This test verifies frame-exact splitting with zero tolerance.

- [ ] `test_uneven_songs` — Generate multi-song PCM with `durations = [2.5, 7.0, 1.5, 4.0]` (4 songs with different lengths). Compute boundaries: `[120000, 456000, 528000]`. Run the pipeline. Assert: 4 output files are produced. Assert each file has the correct byte count within a tolerance of 1 frame (to account for any floating-point frame calculation differences): file 0 = `int(2.5*48000)*4 = 480000` bytes, file 1 = `int(7.0*48000)*4 = 1344000` bytes, file 2 = `int(1.5*48000)*4 = 288000` bytes, file 3 = `int(4.0*48000)*4 = 768000` bytes. Assert: sum of all file sizes equals `len(pcm_data)`.

- [ ] `test_single_song_no_boundaries` — Generate sine PCM with `duration_seconds=10.0` (1 song, no splits). Pass empty boundaries list `[]` to `_run_pipeline()`. Assert: exactly 1 output file is produced. Assert: file size equals `int(10.0*48000)*4 = 1920000` bytes. Assert: the output bytes match the input PCM bytes exactly (no data loss or corruption).

- [ ] `test_very_short_songs` — Generate multi-song PCM with `durations = [0.5, 0.5, 0.5]` (3 very short songs, 1.5s total). Boundaries at `[24000, 48000]`. Run the pipeline. Assert: 3 output files are produced. Assert: each file is `24000 * 4 = 96000` bytes. This tests that the pipeline handles sub-chunk-duration songs correctly (at 100ms chunk size, each 0.5s song is only 5 chunks). Assert: total bytes equals `len(pcm_data)`.

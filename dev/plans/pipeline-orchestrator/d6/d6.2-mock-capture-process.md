# D6.2 — Mock Capture Process

## Deliverable
D6 — Integration Tests

## Prerequisites
- D6.1 (Synthetic Audio Test Harness) -- need `generate_sine_pcm()` / `generate_multi_song_pcm()` to produce PCM data fed to the mock
- `CaptureProcessManager` interface from `src/dreamsync/capture/capture_process.py` -- the mock must be a drop-in replacement, matching its public API: `start(device_name=None)`, `stop()`, `is_alive()`, `restart(device_name=None)`, `.stdout` property
- Python `io.BytesIO` for in-memory stream simulation

## Description

`MockCaptureProcess` is a test double that replaces `CaptureProcessManager` in integration tests. Instead of spawning a real FFmpeg subprocess and reading from a DirectShow audio device, it reads from an in-memory `BytesIO` stream containing pre-generated synthetic PCM data.

This mock allows the full pipeline -- from PCM reading through chunk splitting to file output -- to run without any real audio hardware, FFmpeg binary, or VB-Cable installation. The producer thread in `CaptureOrchestrator` reads from `MockCaptureProcess.stdout` exactly as it would read from `CaptureProcessManager.stdout`, making the mock completely transparent to the orchestrator.

The mock also supports the `restart()` method (used by `RecoveryManager` during failure recovery), which resets the stream to the beginning of the PCM data. This enables testing of crash-recovery scenarios where the capture process is restarted and the pipeline resumes reading from the beginning.

### Class Definition

```python
from io import BytesIO


class MockCaptureProcess:
    """Drop-in replacement for CaptureProcessManager that reads from a BytesIO.

    Simulates the capture process lifecycle (start/stop/restart) using an
    in-memory byte stream instead of a real FFmpeg subprocess.

    Parameters
    ----------
    pcm_data:
        Raw PCM bytes to serve as the audio stream.  Typically produced by
        ``generate_sine_pcm()`` or ``generate_multi_song_pcm()``.
    """

    def __init__(self, pcm_data: bytes) -> None:
        self._data = pcm_data
        self._stream: BytesIO | None = None

    @property
    def stdout(self) -> BytesIO | None:
        """Binary stream that the producer thread reads from.

        Returns None before ``start()`` is called or after ``stop()``
        has closed the stream.
        """
        return self._stream

    def start(self, device_name: str | None = None) -> None:
        """Open the in-memory stream for reading.

        The ``device_name`` parameter is accepted for API compatibility
        with ``CaptureProcessManager.start()`` but is ignored.
        """
        self._stream = BytesIO(self._data)

    def stop(self) -> int:
        """Close the stream and return an exit code.

        Returns 0 (success) to match the CaptureProcessManager convention
        where ``stop()`` returns the subprocess exit code.
        """
        if self._stream is not None:
            self._stream.close()
        return 0

    def is_alive(self) -> bool:
        """Return True if the stream is open and readable."""
        return self._stream is not None and not self._stream.closed

    def restart(self, device_name: str | None = None) -> None:
        """Stop and re-start the stream, resetting to the beginning.

        Used by ``RecoveryManager.handle_capture_failure()`` during
        crash recovery testing.
        """
        self.stop()
        self.start(device_name)
```

### API Compatibility Table

| CaptureProcessManager method | MockCaptureProcess behavior |
|------------------------------|----------------------------|
| `start(device_name=None)` | Creates new `BytesIO(self._data)` |
| `stop()` | Closes the BytesIO stream, returns 0 |
| `is_alive()` | Returns `True` if stream is open |
| `restart(device_name=None)` | Calls `stop()` then `start()` |
| `.stdout` (property) | Returns the BytesIO stream |

### Stream Behavior

When the producer thread reads from `MockCaptureProcess.stdout` via `pcm_reader.read_chunks()`:

1. `BytesIO.read(n)` returns up to `n` bytes from the in-memory buffer
2. When all PCM data has been read, `BytesIO.read(n)` returns `b""` (empty bytes)
3. `read_chunks()` detects EOF and the iterator is exhausted
4. The producer loop exits naturally, calling `AudioBuffer.signal_eof()`

This mirrors exactly what happens when a real FFmpeg process exits and its stdout pipe is closed.

### Usage in Integration Tests

```python
# Create mock capture with 15s of multi-song PCM
pcm = generate_multi_song_pcm([5.0, 5.0, 5.0])
mock_capture = MockCaptureProcess(pcm)

# Pass to CaptureOrchestrator in place of CaptureProcessManager
orchestrator = CaptureOrchestrator(
    capture_manager=mock_capture,
    ...
)
```

### Failure Injection Variant

For failure-injection tests (D6.8), a subclass or wrapper can be used to simulate crashes:

```python
class FailingCaptureProcess(MockCaptureProcess):
    """Mock that raises after a specified number of bytes read."""

    def __init__(self, pcm_data: bytes, fail_after_bytes: int) -> None:
        super().__init__(pcm_data)
        self._fail_after = fail_after_bytes

    def start(self, device_name=None):
        super().start(device_name)
        # Wrap stdout with a FailingStream that raises after N bytes
        self._stream = _FailingStream(self._data, self._fail_after)
```

This variant is documented here for reference but will be implemented inline in D6.8 test code.

## Test Cases

Test file: `dev/tests/test_capture_integration.py`

- [ ] `test_mock_capture_start_stop` — Create `MockCaptureProcess` with 1 second of sine PCM (192000 bytes). Assert `is_alive()` returns `False` before `start()`. Call `start()`. Assert `is_alive()` returns `True`. Assert `stdout` is not `None`. Call `stop()` and capture the return value. Assert return value is `0`. Assert `is_alive()` returns `False`.

- [ ] `test_mock_capture_stdout_reads` — Create `MockCaptureProcess` with a known 5-byte payload `b"\x01\x02\x03\x04\x05"`. Call `start()`. Read all bytes from `stdout` via `stdout.read()`. Assert the result equals the original payload exactly. Assert that a subsequent `stdout.read()` returns `b""` (EOF).

- [ ] `test_mock_capture_restart` — Create `MockCaptureProcess` with 100 bytes of PCM data. Call `start()`. Read 50 bytes from `stdout`. Call `restart()`. Assert `is_alive()` is `True`. Read all bytes from `stdout`. Assert the result is the full 100 bytes (stream was reset to beginning). This verifies that `restart()` creates a fresh `BytesIO` from the original data.

## Description

These tests verify that the pipeline produces correct JSON sidecar files alongside each output audio segment. Sidecars are critical for downstream processing -- they tell consumers where each segment sits in the timeline, what song it corresponds to, and whether any gaps occurred during capture.

The test class validates three key properties of sidecars:
1. **Existence**: Every output segment has a corresponding `.json` sidecar file
2. **Content**: Sidecars contain the required fields (`startFrame`, `endFrame`, `segmentIndex`, and optionally `songTitle`, `artist`, `album`)
3. **Contiguity**: Frame ranges across sidecars are contiguous with no gaps or overlaps (`endFrame` of segment N equals `startFrame` of segment N+1)

These tests exercise the `on_segment_complete` callback in `SplitProcessor`, the `MetadataWriter.write_sidecar()` method, and the metadata flow from `TimingIntegrator` through `BoundaryEntry.metadata` to the sidecar output.

### Pipeline Wiring with Metadata

Extends the `_run_pipeline()` pattern from D6.4 to include `MetadataWriter`:

```python
class TestMetadataSidecars:
    """Verify JSON sidecar files are produced alongside each segment."""

    def _run_pipeline_with_metadata(
        self,
        pcm_data: bytes,
        boundaries: list[int],
        output_dir: str,
        song_metadata: list[dict] | None = None,
    ) -> tuple[list[str], list[str]]:
        """Run pipeline and return (audio_files, sidecar_files).

        Parameters
        ----------
        song_metadata:
            Optional list of dicts, one per song, with keys like
            'song_title', 'artist', 'album'.  If provided, metadata is
            associated with each segment via the on_segment_complete callback.
        """
        audio_files = []
        sidecar_files = []
        writer = MetadataWriter(output_dir=output_dir)

        def start_encoder(segment_index: int):
            path = os.path.join(output_dir, f"segment_{segment_index:06d}.mp3")
            audio_files.append(path)
            encoder = MockEncoderProcess(path)
            encoder.start()
            return encoder

        def on_segment_complete(segment_index, start_frame, end_frame):
            meta = SegmentMetadata(
                start_frame=start_frame,
                end_frame=end_frame,
                segment_index=segment_index,
                sample_rate=SAMPLE_RATE,
                channels=2,
                bitrate="192k",
            )
            # Attach song metadata if provided
            if song_metadata and segment_index < len(song_metadata):
                song = song_metadata[segment_index]
                meta.song_title = song.get("song_title")
                meta.artist = song.get("artist")
                meta.album = song.get("album")

            mp3_path = audio_files[segment_index]
            sidecar_path = writer.write_sidecar(mp3_path, meta)
            sidecar_files.append(sidecar_path)

        processor = SplitProcessor(
            boundaries=boundaries,
            start_encoder=start_encoder,
            on_segment_complete=on_segment_complete,
        )

        mock_capture = MockCaptureProcess(pcm_data)
        mock_capture.start()
        processor.run(read_chunks(mock_capture.stdout, chunk_ms=100))
        mock_capture.stop()

        return audio_files, sidecar_files
```

### JSON Sidecar Format Reference

Each `.json` sidecar file has this structure (from `MetadataWriter._build_payload()`):

```json
{
  "startFrame": 0,
  "endFrame": 240000,
  "segmentDurationFrames": 240000,
  "segmentDurationSeconds": 5.0,
  "plannedStartTime": null,
  "plannedEndTime": null,
  "songTitle": "Song Name",
  "artist": "Artist Name",
  "album": "Album Name",
  "segmentIndex": 0,
  "sampleRate": 48000,
  "channels": 2,
  "bitrate": "192k",
  "sourceTimingData": null,
  "outputFile": null,
  "captureSessionId": null,
  "gaps": null
}
```

### Sidecar Verification Helpers

```python
def _read_sidecar(path: str) -> dict:
    """Read and parse a JSON sidecar file."""
    with open(path, "r", encoding="utf-8") as f:
        return json.load(f)

def _assert_required_fields(sidecar: dict) -> None:
    """Assert all required fields are present."""
    assert "startFrame" in sidecar
    assert "endFrame" in sidecar
    assert "segmentIndex" in sidecar
    assert "segmentDurationFrames" in sidecar
    assert "segmentDurationSeconds" in sidecar
    assert "sampleRate" in sidecar
    assert isinstance(sidecar["startFrame"], int)
    assert isinstance(sidecar["endFrame"], int)
    assert isinstance(sidecar["segmentIndex"], int)
```

Assert: `segmentDurationFrames` of segment 0 is 240000. Assert: `segmentDurationSeconds` of segment 0 is approximately 5.0.

- [ ] `test_sidecar_contains_song_metadata` — Generate multi-song PCM with `durations = [5.0, 5.0]` (2 songs). Provide song metadata: `[{"song_title": "First Song", "artist": "Test Artist", "album": "Test Album"}, {"song_title": "Second Song", "artist": "Another Artist", "album": "Another Album"}]`. Run the pipeline. Read both sidecar files. Assert: sidecar 0 has `songTitle == "First Song"`, `artist == "Test Artist"`, `album == "Test Album"`. Assert: sidecar 1 has `songTitle == "Second Song"`, `artist == "Another Artist"`, `album == "Another Album"`. This verifies that per-song metadata flows through the boundary system to the sidecar output.

- [ ] `test_sidecar_frame_positions_contiguous` — Generate multi-song PCM with `durations = [2.0, 3.0, 5.0, 1.0]` (4 songs). Run the pipeline. Read all 4 sidecar files. Assert: `endFrame` of segment 0 equals `startFrame` of segment 1. Assert: `endFrame` of segment 1 equals `startFrame` of segment 2. Assert: `endFrame` of segment 2 equals `startFrame` of segment 3. Assert: `startFrame` of segment 0 is 0 (pipeline starts at frame 0). Assert: `endFrame` of segment 3 equals the total frame count (`sum(int(d*48000) for d in durations)`). This verifies there are no gaps or overlaps in the frame timeline -- every frame is accounted for exactly once across all segments.

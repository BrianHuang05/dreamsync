## Description

These tests verify the pipeline's resilience to runtime failures by injecting controlled faults into the capture and encoder processes. The pipeline must handle failures gracefully: restarting the capture process after a crash, falling back to raw PCM output when the encoder fails, and eventually giving up without corrupting data when all recovery options are exhausted.

Four failure scenarios are tested:
1. **Capture crash mid-stream**: The capture process raises an exception partway through the audio stream. The pipeline should restart capture, record the gap, and continue producing output.
2. **Capture retries exhausted**: The capture process always fails. After exhausting all retry attempts (default 5), the pipeline should stop gracefully without crashing, finalizing any partial segments.
3. **Encoder crash with raw fallback**: An encoder returns a non-zero exit code. After retry fails, the pipeline should write a `.raw` fallback file containing the raw PCM data.
4. **Encoder total failure with segment skip**: Both the encoder and the raw fallback fail. The pipeline should skip that segment and continue producing subsequent segments.

These tests use specialized mock variants that simulate failures at controlled points.

### Failing Capture Mock

A specialized mock that raises an exception after a configurable number of bytes have been read:

```python
from io import BytesIO


class FailingStream:
    """BytesIO wrapper that raises OSError after N bytes have been read."""

    def __init__(self, data: bytes, fail_after_bytes: int) -> None:
        self._stream = BytesIO(data)
        self._fail_after = fail_after_bytes
        self._bytes_read = 0
        self._has_failed = False

    def read(self, n: int = -1) -> bytes:
        if self._has_failed:
            # After failure, return remaining data (simulating restart)
            return self._stream.read(n)
        result = self._stream.read(n)
        self._bytes_read += len(result)
        if self._bytes_read >= self._fail_after:
            self._has_failed = True
            raise OSError("Simulated capture process crash")
        return result

    def close(self):
        self._stream.close()

    @property
    def closed(self):
        return self._stream.closed


class FailingCaptureProcess(MockCaptureProcess):
    """MockCaptureProcess that crashes after a specified number of bytes.

    After the crash, ``restart()`` recovers and serves remaining data.
    """

    def __init__(self, pcm_data: bytes, fail_after_bytes: int) -> None:
        super().__init__(pcm_data)
        self._fail_after = fail_after_bytes
        self._crash_count = 0

    def start(self, device_name=None):
        if self._crash_count == 0:
            # First start: use FailingStream
            self._stream = FailingStream(self._data, self._fail_after)
        else:
            # After restart: serve remaining data normally
            self._stream = BytesIO(self._data[self._fail_after:])

    def restart(self, device_name=None):
        self._crash_count += 1
        self.stop()
        self.start(device_name)


class AlwaysFailingCaptureProcess(MockCaptureProcess):
    """MockCaptureProcess that always raises on read."""

    def start(self, device_name=None):
        self._stream = FailingStream(b"", 0)

    def restart(self, device_name=None):
        self.stop()
        self.start(device_name)
```

### Failing Encoder Mock

```python
class FailingEncoderProcess(MockEncoderProcess):
    """MockEncoderProcess that returns a non-zero exit code."""

    def wait(self, timeout: float = 30.0) -> int:
        return 1  # Non-zero = failure

    def close(self):
        # Write nothing or partial data
        if self._file is not None and not self._file.closed:
            self._file.close()


class TotallyFailingEncoderProcess(MockEncoderProcess):
    """MockEncoderProcess where both encoding and raw fallback fail."""

    def start(self):
        raise OSError("Simulated encoder start failure")

    def write(self, data: bytes):
        raise OSError("Simulated encoder write failure")

    def wait(self, timeout: float = 30.0) -> int:
        return 1
```

## Test Cases

- [ ] `test_capture_crash_mid_stream` — Generate sine PCM of 10 seconds (1920000 bytes). Create a `FailingCaptureProcess` that crashes after 576000 bytes (3 seconds). Create a `RecoveryManager` with `capture_restart_delay=0.0` and `max_capture_retries=5`. Simulate the producer loop: read chunks from the capture process. When `OSError` is raised, call `recovery.handle_capture_failure(frame_position=current_frame)`. Assert: `handle_capture_failure()` returns `True` (recovery succeeded). Assert: `recovery.total_capture_restarts == 1`. Assert: `len(recovery.gaps) == 1` (one gap recorded). Assert: the gap's `start_frame` matches the frame position where the crash occurred. After recovery, continue reading from the restarted capture. Assert: the pipeline produces output containing data from both before and after the crash (total data is less than the original 10s due to the gap, but segments are produced).

- [ ] `test_capture_retries_exhausted` — Create an `AlwaysFailingCaptureProcess` (always raises on read). Create a `RecoveryManager` with `max_capture_retries=3` and `capture_restart_delay=0.0`. Simulate the producer loop. On each failure, call `recovery.handle_capture_failure()`. Assert: after 3 + 1 = 4 calls (initial + 3 retries), `handle_capture_failure()` returns `False` (retries exhausted). Assert: `recovery.total_capture_restarts` is at most 3. Assert: the pipeline stops without raising an unhandled exception. Assert: any partial segments that were open are finalized (closed). This verifies graceful degradation when recovery is impossible.

- [ ] `test_encoder_crash_produces_raw_fallback` — Set up a pipeline where the encoder factory returns a `FailingEncoderProcess` (returns exit code 1 on `wait()`). Generate multi-song PCM with `durations = [3.0, 3.0]`. Run the pipeline. When the encoder fails (detected by non-zero `wait()` return), call `recovery.handle_encoder_failure(segment_info, start_encoder_fn=None)` with `segment_info` containing `output_path` and `pcm_data`. Assert: `handle_encoder_failure()` returns `"fallback"`. Assert: a `.raw` file exists at the fallback path (same name as the `.mp3` but with `.raw` extension). Assert: the `.raw` file contains the correct PCM data for that segment. This verifies the retry -> fallback cascade.

- [ ] `test_encoder_skip_on_total_failure` — Set up a pipeline where the encoder factory returns a `TotallyFailingEncoderProcess` (start() raises, write() raises). Generate multi-song PCM with `durations = [3.0, 3.0, 3.0]` (3 segments). Configure the pipeline so that segment 1 (the middle segment) uses the totally-failing encoder, while segments 0 and 2 use normal `MockEncoderProcess`. Call `recovery.handle_encoder_failure()` for the failed segment with `pcm_data=None` (no PCM buffer available for fallback). Assert: `handle_encoder_failure()` returns `"skipped"`. Assert: no output file exists for segment 1 (`.mp3` or `.raw`). Assert: segments 0 and 2 are still produced correctly with the right byte counts. Assert: `recovery.total_encoder_failures >= 1`. This verifies that a completely failed segment is skipped without affecting other segments.

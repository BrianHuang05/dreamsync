# D6.1 — Synthetic Audio Test Harness

## Deliverable
D6 — Integration Tests

## Prerequisites
- Python `struct` and `math` modules (stdlib)
- Understanding of PCM s16le format: 2 bytes per sample, little-endian signed 16-bit integers
- `BYTES_PER_FRAME` constant from `pcm_reader.py` (= 4 for stereo s16le)

## Description

The synthetic audio test harness provides two pure-Python functions that generate raw PCM audio data for use in integration tests. These functions eliminate the need for real audio devices or pre-recorded WAV files during testing. By generating known waveforms (sine waves at specific frequencies), tests can verify that the pipeline correctly splits, routes, and writes audio data without any external dependencies.

`generate_sine_pcm()` creates a single sine wave at a given frequency and duration, producing raw s16le PCM bytes. `generate_multi_song_pcm()` chains multiple sine waves with distinct frequencies to simulate a multi-song audio stream, where each "song" has a different frequency signature that can be verified after splitting.

Both functions are deterministic -- given the same inputs they always produce the same output -- making them ideal for exact byte-count assertions in split accuracy tests.

### Function: `generate_sine_pcm`

```python
def generate_sine_pcm(
    frequency: float,
    duration_seconds: float,
    sample_rate: int = 48000,
    channels: int = 2,
) -> bytes:
    """Generate raw PCM s16le bytes of a sine wave.

    Parameters
    ----------
    frequency:
        Sine wave frequency in Hz (e.g. 440 for concert A).
    duration_seconds:
        Duration of the generated audio in seconds.
    sample_rate:
        Audio sample rate in Hz.  Default 48000 matches pipeline default.
    channels:
        Number of audio channels.  Default 2 (stereo).  Each channel gets
        the same sample value (mono signal duplicated across channels).

    Returns
    -------
    bytes
        Raw PCM data in s16le format.  Length is exactly
        ``int(duration_seconds * sample_rate) * channels * 2`` bytes.
    """
    import struct, math
    n_frames = int(duration_seconds * sample_rate)
    samples = []
    for i in range(n_frames):
        val = int(32767 * math.sin(2 * math.pi * frequency * i / sample_rate))
        for _ in range(channels):
            samples.append(val)
    return struct.pack(f"<{len(samples)}h", *samples)
```

**Key properties:**
- Output length = `n_frames * channels * 2` bytes (2 bytes per s16le sample)
- Frame count = `int(duration_seconds * sample_rate)` (truncation, not rounding)
- Sample values range from -32767 to +32767 (never exactly -32768)
- Stereo: left and right channels get identical sample values
- At 48000 Hz, 1.0 second = 48000 frames = 192000 bytes (stereo)

### Function: `generate_multi_song_pcm`

```python
def generate_multi_song_pcm(
    song_durations: list[float],
    frequencies: list[float] | None = None,
    sample_rate: int = 48000,
    channels: int = 2,
) -> bytes:
    """Generate PCM with distinct frequencies per song for split verification.

    Simulates a multi-song audio stream where each song is a sine wave at a
    different frequency.  The distinct frequencies allow post-split verification:
    after splitting, each output file should contain only one frequency.

    Parameters
    ----------
    song_durations:
        List of song durations in seconds (e.g. [5.0, 3.0, 7.0]).
    frequencies:
        Optional list of frequencies in Hz, one per song.  If None, defaults
        to [220, 330, 440, ...] (220 + i*110 for each song).
    sample_rate:
        Audio sample rate in Hz.
    channels:
        Number of audio channels.

    Returns
    -------
    bytes
        Concatenated PCM data for all songs.  Total length equals the sum of
        individual song byte lengths.
    """
    if frequencies is None:
        frequencies = [220 + i * 110 for i in range(len(song_durations))]
    parts = []
    for dur, freq in zip(song_durations, frequencies):
        parts.append(generate_sine_pcm(freq, dur, sample_rate, channels))
    return b"".join(parts)
```

**Key properties:**
- Total output length = sum of all individual `generate_sine_pcm()` outputs
- Default frequencies: 220 Hz (A3), 330 Hz (E4), 440 Hz (A4), 550 Hz (C#5), ...
- Songs are concatenated directly with no silence or gap between them
- Boundary positions can be calculated: song 0 ends at frame `int(dur_0 * sample_rate)`, song 1 ends at frame `int(dur_0 * sample_rate) + int(dur_1 * sample_rate)`, etc.

### Byte Count Calculation Reference

For use in assertions throughout D6 tests:

```python
# Bytes per frame (stereo s16le)
BYTES_PER_FRAME = channels * 2  # = 4 for stereo

# Expected byte count for a duration
def expected_bytes(duration_seconds: float, sample_rate: int = 48000, channels: int = 2) -> int:
    n_frames = int(duration_seconds * sample_rate)
    return n_frames * channels * 2

# Examples:
# 1.0s @ 48kHz stereo = 48000 * 4 = 192000 bytes
# 5.0s @ 48kHz stereo = 240000 * 4 = 960000 bytes
# 0.5s @ 48kHz stereo = 24000 * 4 = 96000 bytes
# 3.0s @ 48kHz stereo = 144000 * 4 = 576000 bytes
```

## Test Cases

Test file: `dev/tests/test_capture_integration.py` (or a dedicated helper test file)

- [ ] `test_sine_pcm_length` — Generate a sine wave with `frequency=440, duration_seconds=1.0, sample_rate=48000, channels=2`. Assert the returned bytes length is exactly `48000 * 2 * 2 = 192000` bytes. Repeat with `duration_seconds=5.0` and assert length is `240000 * 4 = 960000` bytes. Repeat with `channels=1` and assert length is halved. Repeat with `sample_rate=44100` and assert `int(1.0 * 44100) * 2 * 2 = 176400` bytes.

- [ ] `test_multi_song_pcm_length` — Generate multi-song PCM with `song_durations=[5.0, 3.0, 7.0]` at default settings. Assert total length equals `(int(5.0*48000) + int(3.0*48000) + int(7.0*48000)) * 4 = (240000 + 144000 + 336000) * 4 = 2880000` bytes. Verify this also equals `generate_sine_pcm(220, 5.0) + generate_sine_pcm(330, 3.0) + generate_sine_pcm(440, 7.0)` concatenated.

- [ ] `test_sine_pcm_not_silent` — Generate a sine wave with any nonzero frequency (e.g. 440 Hz) and assert that the bytes are not all zeros. Specifically: unpack the first 100 samples as `<100h` and verify that at least some samples are nonzero. Also verify that max(abs(sample)) > 10000 to confirm the sine wave has significant amplitude.

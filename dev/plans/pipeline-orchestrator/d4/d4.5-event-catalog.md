# D4.5 — Event Catalog

## Deliverable
D4 — Recovery & Logging

## Prerequisites
- D4.4 (PipelineLogger Wiring) — `self._logger` available in `CaptureOrchestrator`
- D2 (Capture Data Path) — capture, encoder, and split events emitted from data path methods
- D3 (Boundary Control Path) — boundary and timing events emitted from control path methods
- D4.2 (Capture Failure Recovery) — recovery events emitted from producer thread
- D4.3 (Encoder Failure Recovery) — recovery events emitted from `_on_segment_complete()`

## Description

Define and document the complete catalog of structured events that the `CaptureOrchestrator` emits through `PipelineLogger` during its lifecycle. This catalog serves as the contract between the pipeline and any downstream log consumers (monitoring dashboards, post-session analysis tools, debugging workflows). Each event has a fixed category, event name, log level, and trigger condition.

This sub-component is primarily a documentation and validation task. The actual `self._logger.log()` / `self._logger.*_event()` calls are placed in the code by D2, D3, D4.2, D4.3, and D4.7. This plan ensures all events follow a consistent naming convention, use appropriate log levels, and are verifiable through tests.

### Complete Event Catalog

#### Pipeline Lifecycle Events

| Category | Event | Level | Logger Call | Where Emitted | Data Fields |
|----------|-------|-------|-------------|---------------|-------------|
| `pipeline` | `started` | INFO | `self._logger.log("INFO", "pipeline", "started", ...)` | `start()` method, after all threads launched | `{"device_name": str}` |
| `pipeline` | `stopping` | INFO | `self._logger.log("INFO", "pipeline", "stopping", ...)` | `stop()` method, before signaling threads | `None` |
| `pipeline` | `stopped` | INFO | `self._logger.log("INFO", "pipeline", "stopped", ...)` | `stop()` method, after all threads joined | `self.stats` dict (see D4.7) |

#### Capture Events

| Category | Event | Level | Logger Call | Where Emitted | Data Fields |
|----------|-------|-------|-------------|---------------|-------------|
| `capture` | `ffmpeg_started` | INFO | `self._logger.capture_event("ffmpeg_started", ...)` | After `self._capture.start()` succeeds | `{"device_name": str, "pid": int}` |
| `capture` | `ffmpeg_stopped` | INFO | `self._logger.capture_event("ffmpeg_stopped", ...)` | After `self._capture.stop()` returns | `{"exit_code": int}` |
| `capture` | `chunk_read` | DEBUG | `self._logger.log("DEBUG", "capture", "chunk_read", ...)` | Each iteration of `read_chunks()` in `_producer_loop()` | `{"chunk_bytes": int}` |

| Category | Event | Level | Logger Call | Where Emitted | Data Fields |
|----------|-------|-------|-------------|---------------|-------------|

#### Recovery Events

| Category | Event | Level | Logger Call | Where Emitted | Data Fields |
|----------|-------|-------|-------------|---------------|-------------|
| `recovery` | `capture_failure` | WARNING | `self._logger.recovery_event("capture_failure", ...)` | In `_producer_loop()` when `read_chunks()` raises | `{"error": str, "error_type": str}` |
| `recovery` | `capture_restarted` | INFO | `self._logger.recovery_event("capture_restarted", ...)` | After successful capture recovery | `None` |
| `recovery` | `capture_unrecoverable` | ERROR | `self._logger.log("ERROR", "recovery", "capture_unrecoverable", ...)` | When capture retries exhausted | `{"retries_exhausted": True}` |
| `recovery` | `encoder_failure` | WARNING | `self._logger.recovery_event("encoder_failure", ...)` | In `_on_segment_complete()` when encoder exits non-zero | `{"segment_index": int, "exit_code": int, "stderr": str}` |
| `recovery` | `encoder_recovery_result` | INFO | `self._logger.recovery_event("encoder_recovery_result", ...)` | After encoder recovery cascade completes | `{"segment_index": int, "result": str}` |

### Log Level Conventions

| Level | Usage | Console | File |
|-------|-------|---------|------|
| `DEBUG` | High-volume per-chunk events, internal state transitions | No (filtered) | Yes |
| `INFO` | Normal pipeline lifecycle, successful operations | Yes | Yes |
| `WARNING` | Failures that trigger recovery, drift corrections | Yes | Yes |
| `ERROR` | Unrecoverable failures (retries exhausted) | Yes | Yes |

### Event Naming Conventions

- **Category** — The pipeline subsystem: `pipeline`, `capture`, `encoder`, `split`, `boundary`, `timing`, `recovery`
- **Event** — Snake-case action: `started`, `stopped`, `ffmpeg_started`, `chunk_read`, `segment_complete`, `capture_failure`
- **Data** — Always a dict or `None`. Keys are snake_case. Values are JSON-serializable primitives.
- **frame_position** — Always an `int` representing the global frame counter at the time of the event. Passed as a dedicated parameter, not inside `data`.

### Placing Event Calls in Code

Each event call is placed at a specific location in `orchestrator.py`. The following is a summary of where each call goes (the actual code changes are in D2, D3, D4.2, D4.3, D4.7):

```python
# In start():
self._logger.log("INFO", "pipeline", "started", ...)
self._logger.capture_event("ffmpeg_started", ...)

# In _producer_loop():
self._logger.log("DEBUG", "capture", "chunk_read", ...)   # per chunk
self._logger.recovery_event("capture_failure", ...)         # on exception
self._logger.recovery_event("capture_restarted", ...)       # on recovery
self._logger.log("ERROR", "recovery", "capture_unrecoverable", ...)  # retries exhausted

# In _consumer_loop():
self._logger.split_event("boundary_crossed", ...)           # on boundary
self._logger.encoder_event("encoder_started", ...)          # new encoder
self._logger.encoder_event("encoder_finished", ...)         # encoder done

# In _on_segment_complete():
self._logger.split_event("segment_complete", ...)           # segment finalized
self._logger.recovery_event("encoder_failure", ...)         # encoder failed
self._logger.recovery_event("encoder_recovery_result", ...) # cascade result

# In _update_boundaries() (called from timing thread or external):
self._logger.boundary_event("queue_updated", ...)
self._logger.log("DEBUG", "boundary", "boundary_locked", ...)

# In _check_drift() (called periodically):
self._logger.timing_event("timing_update", ...)
self._logger.timing_event("drift_check", ...)
self._logger.log("WARNING", "timing", "drift_correction", ...)

# In stop():
self._logger.log("INFO", "pipeline", "stopping", ...)
self._logger.capture_event("ffmpeg_stopped", ...)
self._logger.log("INFO", "pipeline", "stopped", ...)
```

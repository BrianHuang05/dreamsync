# Deliverable 1.1: Install VB-Audio Virtual Cable

## Phase

[Phase 1: Audio Routing & Environment Setup](../phase1-audio-routing.md)

## Prerequisites

- Windows 11 machine
- Administrator access
- Internet connection for download

## Description

Download and install the VB-Audio Virtual Cable driver, which creates a virtual audio loopback pair: a playback device (CABLE Input) and a recording device (CABLE Output). Audio sent to CABLE Input is internally routed to CABLE Output, allowing capture without physical hardware.

### Steps

1. Download the VB-Audio Virtual Cable installer from https://vb-audio.com/Cable/
2. Extract the downloaded archive
3. Right-click the installer and select "Run as administrator"
4. Complete the installation wizard
5. Reboot the system (required for driver activation)

### Post-Install Verification

After reboot, confirm two new audio devices exist:

**Playback device:**
```
CABLE Input (VB-Audio Virtual Cable)
```

**Recording device:**
```
CABLE Output (VB-Audio Virtual Cable)
```

Location: Windows Settings > System > Sound > More sound settings

## Completion Criteria

1. VB-Audio Virtual Cable driver installed without errors
2. System rebooted after installation
3. "CABLE Input (VB-Audio Virtual Cable)" visible in Playback devices
4. "CABLE Output (VB-Audio Virtual Cable)" visible in Recording devices

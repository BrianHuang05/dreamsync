# Deliverable 1.2: Configure Application Audio Routing

## Phase

[Phase 1: Audio Routing & Environment Setup](../phase1-audio-routing.md)

## Prerequisites

- Deliverable 1.1 complete (VB-Audio Virtual Cable installed)
- Target audio application installed and running

## Description

Route the target application's audio output to the CABLE Input virtual device. This diverts the application's audio stream from the physical speakers into the virtual cable, making it available for capture on CABLE Output.

### Steps

1. Open Windows Settings > System > Sound
2. Scroll to "Volume mixer" (or Advanced sound options > App volume and device preferences)
3. Locate the target application in the list
4. Change its Output Device from default to **CABLE Input (VB-Audio Virtual Cable)**

### Alternative: Per-App Sound Settings (Windows 11)

1. Right-click the speaker icon in the system tray
2. Select "Sound settings"
3. Under "Advanced", click "Volume mixer"
4. Find the target app and set its output to CABLE Input

### Note on Monitoring

After routing, the target app's audio will no longer play through speakers. To hear audio while capturing, configure VB-Audio's monitoring feature or use a secondary virtual cable to split the output.

## Completion Criteria

1. Target application's output device is set to "CABLE Input" in Windows Volume Mixer
2. The routing persists across app restarts (verify by restarting the target app)
3. No audio from the target application plays through physical speakers (confirming routing is active)

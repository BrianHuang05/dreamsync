# Deliverable 1.3: Verify Audio Signal Path

## Phase

[Phase 1: Audio Routing & Environment Setup](../phase1-audio-routing.md)

## Prerequisites

- Deliverable 1.2 complete (audio routing configured)

## Description

Confirm that audio from the target application is successfully flowing through the virtual cable by observing the CABLE Output recording device's level meter in Windows Sound settings.

### Steps

1. Open Windows Settings > System > Sound > More sound settings
2. Navigate to the Recording tab
3. Locate "CABLE Output (VB-Audio Virtual Cable)"
4. Start playing audio in the target application
5. Observe the level meter next to CABLE Output

### Expected Result

The level meter should show real-time audio activity (green bars moving) when the target application is producing sound. The meter should be silent when the application is paused or stopped.

### Troubleshooting

| Symptom                     | Likely Cause                          | Fix                                           |
|-----------------------------|---------------------------------------|------------------------------------------------|
| No level activity           | App output not set to CABLE Input     | Re-check Volume Mixer output device setting    |
| Level activity but very low | App volume too low                    | Increase app volume                            |
| CABLE Output not listed     | Driver not installed or not loaded    | Reinstall VB-Audio Virtual Cable and reboot    |

## Completion Criteria

1. CABLE Output level meter shows clear audio activity when target application plays audio
2. CABLE Output level meter is silent when target application is paused
3. Signal visually matches expected audio patterns (e.g., loud during playback, quiet during silence)

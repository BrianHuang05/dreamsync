# Deliverable 5.1: Metadata Sidecar Files

## Phase

[Phase 5: Metadata, Logging & Recovery](../phase5-metadata-recovery.md)

## Prerequisites

- Phase 3 complete (static splitting produces MP3 files)
- Deliverable 5.4 complete (logging system available)
- Song metadata available from external timing source

## Description

For every MP3 segment file produced by the pipeline, generate a companion JSON sidecar file containing frame-level metadata, timing information, and song details. These files enable post-hoc verification, debugging, and integration with downstream systems.

### Sidecar Filename

Same as the MP3 file with `.json` extension:

```
2026-03-04_14-30-00_segment_000001.mp3
2026-03-04_14-30-00_segment_000001.json
```

### JSON Schema

```json
{
    "startFrame": 0,
    "endFrame": 720000,
    "segmentDurationFrames": 720000,
    "segmentDurationSeconds": 15.0,
    "plannedStartTime": "2026-03-04T14:30:00.000Z",
    "plannedEndTime": "2026-03-04T14:30:15.000Z",
    "songTitle": "Time",
    "artist": "Pink Floyd",
    "album": "The Dark Side of the Moon",
    "segmentIndex": 0,
    "sampleRate": 48000,
    "channels": 2,
    "bitrate": "192k",
    "sourceTimingData": {
        "currentPlaybackTime": 15.0,
        "songDuration": 30.0,
        "remainingAtCaptureStart": 15.0
    },
    "outputFile": "2026-03-04_14-30-00_segment_000001.mp3",
    "captureSessionId": "abc123"
}
```

### Implementation Details

1. Collect metadata during segment processing (start/end frames from split logic)
2. Write JSON atomically (write to temp file, then rename) to prevent partial files
3. Include all available song metadata from the timing data source
4. Timestamp fields use ISO 8601 format

### Interface

```python
class MetadataWriter:
    def __init__(self, output_dir: str)

    def write_sidecar(self, mp3_path: str, metadata: SegmentMetadata) -> str:
        """Write JSON sidecar file. Returns path to sidecar file."""
```

## Completion Criteria

1. Every MP3 file has a companion `.json` sidecar in the same directory
2. `segmentDurationFrames` equals `endFrame - startFrame`
3. `segmentDurationSeconds` equals `segmentDurationFrames / sampleRate`
4. All required fields are populated (nulls allowed for unavailable song metadata)
5. JSON is valid and parseable
6. Sidecar files are written atomically (no partial writes on crash)

# Deliverable 2.4: Frame Counter & Buffer

## Phase

[Phase 2: PCM Capture Engine](../phase2-pcm-capture.md)

## Prerequisites

- Deliverable 2.3 complete (PCM stream reader functional)

## Description

Implement a global frame counter that tracks the total number of audio frames processed since capture began, and a buffer layer that decouples the capture rate from downstream consumption (split logic, encoders).

### Frame Counter

The frame counter is the pipeline's master clock. All segment boundaries are expressed in frames, making the counter the authoritative reference for split decisions.

```
frames_processed += len(chunk) // BYTES_PER_FRAME
```

After N seconds of capture:
```
expected_frames = N * SAMPLE_RATE
```

### Buffer Layer

The buffer sits between the PCM reader and the split logic:

```
Capture FFmpeg -> PCM Reader -> [Buffer] -> Split Logic -> Encoders
```

**Purpose:**
- Absorb timing jitter between capture and encoding
- Allow the split logic to process at its own pace without blocking capture
- Provide a point for backpressure signaling if encoders fall behind

**Implementation options:**
1. **Simple queue** (`collections.deque` or `queue.Queue`) - recommended for single-threaded
2. **Ring buffer** - if fixed memory footprint is needed
3. **Thread-safe queue** - if capture and processing run on separate threads

**Recommended:** `queue.Queue` with a max size of ~10 chunks (1 second of audio at 100ms chunks).

### Interface

```python
class AudioBuffer:
    def put(self, chunk: bytes) -> None
    def get(self) -> bytes  # blocks until available
    def frames_processed(self) -> int
    def bytes_processed(self) -> int
    def elapsed_seconds(self) -> float
```

## Completion Criteria

1. Frame counter increments by `chunk_bytes / BYTES_PER_FRAME` for every chunk processed
2. After 10 seconds of capture, `frames_processed` equals `480,000` (+/- 0)
3. Buffer holds at least 1 second of audio without blocking capture
4. `elapsed_seconds()` returns `frames_processed / SAMPLE_RATE`
5. Buffer provides clean get/put interface for downstream consumers

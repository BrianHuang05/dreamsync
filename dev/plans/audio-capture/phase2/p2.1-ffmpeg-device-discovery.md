# Deliverable 2.1: FFmpeg Device Discovery

## Phase

[Phase 2: PCM Capture Engine](../phase2-pcm-capture.md)

## Prerequisites

- Phase 1 complete (audio routing verified)
- FFmpeg installed and on PATH

## Description

Implement a function that uses FFmpeg's DirectShow device enumeration to discover available audio capture devices and locate the CABLE Output virtual device by name. This avoids hardcoding device names and allows the pipeline to adapt to different configurations.

### FFmpeg Discovery Command

```
ffmpeg -list_devices true -f dshow -i dummy
```

This outputs a list of DirectShow audio and video devices. The target device will appear as:

```
"CABLE Output (VB-Audio Virtual Cable)"
```

### Implementation Details

1. Spawn FFmpeg with the device listing arguments
2. Parse stderr output (FFmpeg writes device lists to stderr)
3. Extract audio device names from the `DirectShow audio devices` section
4. Match against expected pattern: device name containing "CABLE Output" or "VB-Audio"
5. Return the full device name string for use in capture commands

### Interface

```
discover_audio_device(pattern: str = "CABLE Output") -> str | None
```

- Returns the full device name if found
- Returns `None` if no matching device is found

## Completion Criteria

1. Function spawns FFmpeg and parses device list from stderr
2. Correctly identifies "CABLE Output (VB-Audio Virtual Cable)" from the output
3. Returns `None` gracefully when no matching device exists
4. Works when multiple audio devices are present (selects correct one)

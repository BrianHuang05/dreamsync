# Deliverable 3.3: Split Logic Algorithm

## Phase

[Phase 3: Static Segment Splitting](../phase3-static-splitting.md)

## Prerequisites

- Deliverable 3.1 complete (segment boundary computation)
- Deliverable 3.2 complete (encoder process manager)
- Deliverable 2.4 complete (frame counter and buffer)

## Description

Implement the core split loop that reads PCM chunks from the buffer, tracks the global frame position, and routes audio data to the correct encoder process. When a segment boundary falls within a chunk, the chunk is split at the exact frame boundary: the first portion goes to the current encoder, and the remainder goes to the next encoder.

### State Variables

```python
sample_rate = 48000
bytes_per_frame = 4

current_frame = 0          # global frame counter
segment_index = 0          # index into boundary list
segment_frames_written = 0 # frames written to current segment
boundaries = [...]         # cumulative frame boundaries from 3.1
```

### Algorithm

```
for each chunk from buffer:
    chunk_frames = len(chunk) // bytes_per_frame
    offset = 0

    while chunk_frames > 0:
        frames_remaining = boundaries[segment_index] - current_frame

        if chunk_frames <= frames_remaining:
            # Entire chunk fits in current segment
            encoder.write(chunk[offset:])
            current_frame += chunk_frames
            segment_frames_written += chunk_frames
            chunk_frames = 0

        else:
            # Chunk spans a boundary - split it
            split_bytes = frames_remaining * bytes_per_frame
            encoder.write(chunk[offset : offset + split_bytes])
            current_frame += frames_remaining

            # Close current encoder, start next
            encoder.close()
            segment_index += 1
            segment_frames_written = 0
            encoder = start_next_encoder()

            # Continue with remaining bytes
            offset += split_bytes
            chunk_frames -= frames_remaining
```

### Guarantees

This algorithm guarantees:

1. **No dropped samples:** Every byte from the capture stream is written to exactly one encoder
2. **No duplicated samples:** No byte is written to more than one encoder
3. **Exact boundaries:** Splits occur at the precise frame indicated by the boundary list

### Edge Cases

- **Boundary at chunk start:** `frames_remaining == 0` at loop entry - immediately close and rotate
- **Multiple boundaries in one chunk:** The inner while loop handles this naturally
- **Final segment:** When `segment_index` exceeds boundary list, write all remaining data to last encoder

## Completion Criteria

1. Split loop processes all PCM chunks from buffer without dropping or duplicating bytes
2. Segment transitions occur at exact frame boundaries
3. Mid-chunk splits produce correct byte slicing (verified by frame count)
4. Multiple boundaries within a single chunk are handled correctly
5. Synthetic test: 3 segments of known frame counts produce 3 MP3 files with matching durations
6. Total frames across all segments equals total frames captured

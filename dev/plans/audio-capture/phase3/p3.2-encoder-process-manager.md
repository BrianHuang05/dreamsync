# Deliverable 3.2: Encoder Process Manager

## Phase

[Phase 3: Static Segment Splitting](../phase3-static-splitting.md)

## Prerequisites

- FFmpeg installed and on PATH
- Output directory exists and is writable

## Description

Implement a manager that spawns per-segment FFmpeg encoder processes. Each encoder receives raw PCM on stdin and writes an MP3 file. The manager handles the lifecycle: start, write, close, and wait for exit.

### FFmpeg Encoder Command

```
ffmpeg -hide_banner -loglevel warning
  -f s16le -ac 2 -ar 48000 -i pipe:0
  -c:a libmp3lame -b:a 192k
  "OUTPUT_FILE.mp3"
```

### Implementation Details

**Encoder lifecycle:**

1. **Start:** Spawn FFmpeg with `stdin=PIPE`, `stdout=PIPE`, `stderr=PIPE`
2. **Write:** Pipe raw PCM bytes to FFmpeg's stdin
3. **Close:** Close stdin to signal end-of-input
4. **Wait:** Wait for FFmpeg to finish encoding and exit
5. **Verify:** Check exit code and output file existence

**Key behaviors:**
- Only one encoder is active at a time (sequential segments)
- Closing stdin causes FFmpeg to flush, finalize the MP3, and exit
- The manager should not block the main loop while waiting for FFmpeg to exit (use non-blocking wait or background thread)

### Interface

```python
class EncoderProcess:
    def __init__(self, output_path: str, sample_rate: int = 48000,
                 channels: int = 2, bitrate: str = "192k")
    def start(self) -> None
    def write(self, pcm_data: bytes) -> None
    def close(self) -> None      # close stdin, trigger finalization
    def wait(self) -> int         # wait for exit, return exit code
    def is_alive(self) -> bool
```

### Configuration

| Parameter    | Default  | Description              |
|--------------|----------|--------------------------|
| `sample_rate`| 48000    | Input PCM sample rate    |
| `channels`   | 2        | Input channel count      |
| `bitrate`    | "192k"   | MP3 output bitrate       |

## Completion Criteria

1. Encoder starts FFmpeg with correct arguments for PCM-to-MP3 conversion
2. `write()` successfully pipes PCM data to FFmpeg stdin
3. `close()` triggers FFmpeg to finalize the MP3 file
4. `wait()` returns exit code 0 for successful encoding
5. Output MP3 file exists and is playable after `close()` + `wait()`
6. No zombie processes after encoder lifecycle completes

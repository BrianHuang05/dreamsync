# Deliverable 3.4: File Naming & Output

## Phase

[Phase 3: Static Segment Splitting](../phase3-static-splitting.md)

## Prerequisites

- Deliverable 3.2 complete (encoder process manager)
- Output directory configured

## Description

Implement a deterministic file naming system for output MP3 segments and manage the output directory structure.

### Naming Pattern

**Default (timestamp-based):**

```
YYYY-MM-DD_HH-MM-SS_segment_NNNNNN.mp3
```

Example: `2026-03-04_14-30-00_segment_000001.mp3`

**With metadata (when song info is available):**

```
YYYY-MM-DD_HH-MM-SS_Artist_-_Title.mp3
```

Example: `2026-03-04_14-30-00_Pink_Floyd_-_Time.mp3`

### Implementation Details

1. **Filename sanitization:** Remove or replace characters invalid in filenames (`/ \ : * ? " < > |`)
2. **Collision avoidance:** If file already exists, append `_N` suffix
3. **Segment counter:** Monotonically increasing integer, zero-padded to 6 digits
4. **Output directory:** Configurable, defaults to `./output/`
5. **Directory creation:** Create output directory if it doesn't exist

### Interface

```python
class FileNamer:
    def __init__(self, output_dir: str = "./output", pattern: str = "timestamp")

    def next_filename(self, metadata: dict | None = None) -> str:
        """Return the full path for the next segment file."""

    def sanitize(self, name: str) -> str:
        """Remove invalid filename characters."""
```

### Metadata Dict (optional)

```python
{
    "song_title": "Time",
    "artist": "Pink Floyd",
    "album": "The Dark Side of the Moon"
}
```

## Completion Criteria

1. Filenames are deterministic and monotonically increasing
2. Invalid filesystem characters are sanitized
3. No filename collisions (collision avoidance works)
4. Output directory is created automatically if missing
5. Both timestamp and metadata naming patterns produce valid filenames
6. Filenames are consistent across runs with the same inputs

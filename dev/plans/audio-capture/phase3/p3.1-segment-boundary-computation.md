# Deliverable 3.1: Segment Boundary Computation

## Phase

[Phase 3: Static Segment Splitting](../phase3-static-splitting.md)

## Prerequisites

- Phase 2 complete (frame counter and PCM capture operational)
- Understanding of the timing data format from the external source

## Description

Implement the function that converts external song timing data (durations and current playback position) into an ordered list of cumulative frame boundaries that the split logic will use to trigger segment transitions.

### Input Data

From the external program:

```
currentPlaybackTime: float    # seconds into the current song
songDurations: list[float]    # [d0, d1, d2, d3, d4] in seconds
```

Where `d0` is the duration of the currently playing song.

### Computation

**Step 1: Remaining time in current song**

```
r0 = max(d0 - currentPlaybackTime, 0)
```

**Step 2: Segment durations from "now"**

```
segment_durations = [r0, d1, d2, d3, d4]
```

**Step 3: Convert to frames**

```
segment_frames[i] = round(segment_durations[i] * sample_rate)
```

**Step 4: Cumulative boundaries**

```
boundaries[0] = segment_frames[0]
boundaries[i] = boundaries[i-1] + segment_frames[i]
```

### Example

```
currentPlaybackTime = 15.0
songDurations = [30, 210, 180]
sample_rate = 48000

r0 = 30 - 15 = 15.0
segment_durations = [15.0, 210, 180]
segment_frames = [720000, 10080000, 8640000]
cumulative_boundaries = [720000, 10800000, 19440000]
```

### Interface

```python
def compute_boundaries(
    song_durations: list[float],
    current_playback_time: float,
    sample_rate: int = 48000
) -> list[int]:
    """Returns cumulative frame boundaries relative to capture start."""
```

### Edge Cases

- `currentPlaybackTime >= d0`: r0 = 0, first boundary is at frame 0 (immediate split)
- Empty `songDurations`: returns empty list
- Single song: returns one boundary
- Very short durations (< 1 frame): rounded to 0 frames, boundary collapses

## Completion Criteria

1. Function correctly computes cumulative frame boundaries from timing data
2. Handles edge case where `currentPlaybackTime >= d0` (immediate first split)
3. All boundaries are integers (frame-aligned)
4. Example case produces `[720000, 10800000, 19440000]`
5. Unit tests pass for: normal case, edge cases, single song, many songs

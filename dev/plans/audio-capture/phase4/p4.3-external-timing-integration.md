# Deliverable 4.3: External Timing Integration

## Phase

[Phase 4: Dynamic Rolling Window](../phase4-dynamic-updates.md)

## Prerequisites

- Deliverable 4.1 complete (boundary queue manager)
- Deliverable 4.2 complete (safety margin enforcement)
- External timing data source accessible

## Description

Implement the interface between the external song timing data source and the boundary queue. This component periodically fetches updated timing information, recomputes future boundaries, and applies them to the queue.

### Timing Data Format

From the external source (e.g., Spotify API, show session):

```python
{
    "current_playback_time": 45.2,    # seconds into current song
    "song_durations": [210, 180, 240, 195],  # current + upcoming songs
    "current_song": {
        "title": "Time",
        "artist": "Pink Floyd"
    },
    "track_changed": False  # True if track just changed
}
```

### Refresh Behavior

**Periodic refresh (default every 5 seconds):**

1. Fetch current timing data from external source
2. Call `compute_boundaries()` (from 3.1) with updated data
3. Adjust boundaries for elapsed frames since capture start
4. Call `boundary_queue.replace_future(new_boundaries)` (respects safety margin)

**Track-change event:**

1. External source signals track change
2. Trigger immediate plan refresh (bypass periodic interval)
3. Recompute all future boundaries from new timing data

### Frame Offset Calculation

Boundaries from `compute_boundaries()` are relative to "now." To convert to absolute frame positions:

```python
absolute_boundary = current_frame + relative_boundary
```

Where `current_frame` is the global frame counter from the capture engine.

### Interface

```python
class TimingIntegrator:
    def __init__(self, boundary_queue: BoundaryQueue,
                 frame_counter: FrameCounter,
                 refresh_interval: float = 5.0)

    def update(self, timing_data: dict) -> None:
        """Process new timing data and update boundary queue."""

    def on_track_change(self, timing_data: dict) -> None:
        """Handle track change event with immediate refresh."""

    def start_periodic_refresh(self, fetch_fn: Callable) -> None:
        """Start background periodic refresh using fetch_fn to get timing data."""

    def stop(self) -> None:
        """Stop periodic refresh."""
```

### Error Handling

- External source unavailable: keep existing boundaries, log warning, retry on next interval
- Stale timing data (timestamp too old): log warning, skip update
- Empty duration list: do not modify existing boundaries

## Completion Criteria

1. Periodic refresh fetches timing data and updates future boundaries at configured interval
2. Track-change events trigger immediate boundary recomputation
3. Relative boundaries are correctly converted to absolute frame positions
4. Safety margin is respected (locked boundaries preserved during update)
5. External source failures are handled gracefully (no crash, boundaries preserved)
6. Refresh interval is configurable
7. Integration test: 3 mid-stream timing updates produce correct boundary adjustments

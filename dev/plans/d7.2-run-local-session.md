## Goal

Add `run_local_session()` as the top-level entry point for local show playback, and wire it into `run_session()` so the session system can dispatch to local mode. This mirrors `run_v3_session()` (D5.3) — a thin orchestrator that creates `ShowCache` and `LocalShowSession`, then delegates to `session.run()`.
